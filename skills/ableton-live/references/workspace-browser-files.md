## Scope and first checks
- Use this reference for Live UI decisions and procedures, not as an automation-capability list. A visible Live feature is not proof that an integration can operate it. Check the installed build, edition, device availability, current selection, and available controls before acting; Live 12 builds do not necessarily expose the same feature set.
- Preserve the current Set before structural changes; choose an independent copy when the task must not alter the original. Do not delete files, edit source audio destructively, upload source material to a provider, or redistribute content through this workflow. Verification steps below are checks to perform, not claims of executed tests.
- Start with an installed, authorized Live version appropriate to the task. A license supplies two computer authorizations for use on one computer at a time. Installation, account authorization, updates, and connected-service access remain explicit user decisions.
- A **Live Set** is the editable document; a **Project** is the containing folder for related Sets and dependencies. Saving a Set records its arrangement and settings, not necessarily copies of every audio file it references.

## Configure and navigate the workspace
- Open **Settings** from Options on Windows or Live on macOS, or `Ctrl+,` / `Cmd+,`. Select the tab by the problem rather than changing unrelated defaults:

| Need | Settings and distinctions |
| --- | --- |
| Readability or keyboard focus | **Display & Input**: UI language; separate zoom for the main, second, and Settings windows; Settings zoom changes after releasing the mouse. **Outline View in Focus** marks the active view. Also configure scroll bars, Follow behavior, UI labels, Tab navigation/continuous navigation, and arrow-key clip movement. |
| Pen or drawing behavior | **Display & Input** → Mouse and Pen Input: Pen Tablet Mode, permanent scrub areas, pitch-locked MIDI-note drawing. Application Options restores previously suppressed “Don’t Show Again” dialogs. |
| Appearance | **Theme & Colors**: theme; light/dark or OS-following appearance; warm/cool/neutral tone; high contrast; grid opacity, brightness, color intensity/hue. Track/clip options include default or automatic track colors, Reduced Automatic Colors, and random or track-derived clip colors. |
| Audio I/O or latency | **Audio**: driver, input/output devices, sample rate, latency, calibration test section. macOS supports CoreAudio and **Use System Device** for output following macOS Sound settings; Windows generally uses ASIO and the driver's own device configuration. Recheck the actual output after a system-device change. |
| Network timing or audio | **Link** configures Link time synchronization and Link Audio streaming between compatible network devices; these are different functions. Do not equate synchronized clocks with an established audio route. |
| Hardware MIDI/control/sync | **Tempo & MIDI** configures note I/O, controller use, Tempo Follower/MIDI sync, and resynchronizing hardware that has drifted from Live's MIDI clock. |
| Data and Max | **File & Folder**: Create Analysis Files, Temporary Folder for recordings before the Set is saved, decoding cache, and bundled/external Max selection. Max for Live is included with Suite and can also be used with Standard when available/licensed; do not assume it in every edition. Sample Editor selects a destructive external editor, outside this workflow. |
| Libraries and downloads | **Library**: Pack and User Library locations, Collect Files on Export, connected-source visibility, and Splice download location. |
| Third-party devices | **Plug-Ins**: enabled plug-in folders and plug-in window behavior. VST and Audio Units are separate formats; Audio Units are macOS-only. |
| Recording and clip defaults | **Record, Warp & Launch**: new recording format, Warp/Fade defaults, clip/scene launching, selection, recording, and Exclusive Arm. |
| Account/update policy | **Licenses & Updates**: authorization, automatic updates, and usage data. Do not change these merely to troubleshoot a clip. |

- Use **Info View** (`?` or its bottom-left toggle) to inspect the hovered control's function. For project-specific notes, choose **Edit Info Text** on a track, clip, device, or other supported item, then type in Info View; that text is saved with the Set.
- For guided UI learning, open **Learn View** from Help or `Ctrl+Alt+7` / `Cmd+Option+7`. Filter lessons by topic, mark **Complete Lesson**, and return with the Home button or **< Lessons**. Related-lesson links appear when the home page shows all lessons; modules can update independently of Live.
- Learn View requires Internet access; after reconnecting, use **Reload**. Videos have playback, scrub, volume, subtitle, and picture-in-picture controls. Picture-in-picture closes Learn View, stays above other apps, supports resizing and 15-second skips, and can return via **Learn View →**. Lesson position/video progress persists while Live remains open, not as a promised cross-launch state.
- The **Control Bar** groups browser/configuration; tempo/time signature, metronome, Link and Tempo Follower; scale; Follow/Arrangement position; playback/Arrangement Record; overdub, Automation Arm, Re-Enable Automation, Capture MIDI and Session Record; loop/punch; Draw Mode, Computer MIDI Keyboard, mapping, sample rate/CPU; and the Session/Arrangement selector. Choose the control for the state being changed.
- Inspect the **Status Bar** for errors, available-update notices, analysis progress, selected MIDI note position/pitch/velocity/probability, and precise hovered insert-marker position. Do not infer a location only from screen geometry.
- Switch Session/Arrangement with the view buttons or Navigate menu. `Tab` switches in one window and swaps views across two windows, **unless Use Tab Key to Navigate is enabled**; use `Alt+1` / `Option+1` for Session and `Alt+2` / `Option+2` for Arrangement instead. Switching views changes the display, not playback.
- Double-click a clip for **Clip View**: start/end, looping, scale, audio Warp/transformation or MIDI pitch/time and Transformation/Generative tools; Session clips also expose launch settings and Follow Actions. Double-click a track title for **Device View**. Stack both with their triangle toggles, or show Clip View with `Ctrl+Alt+3` / `Cmd+Option+3` and Device View with `Ctrl+Alt+4` / `Cmd+Option+4`.
- For scale-aware editing, select the intended clip(s), enable **Scale Mode**, and choose **Root Note** and **Scale Name** in Clip View or the Control Bar. The bar reflects the selection; with no clip selected, choices affect subsequently created clips, and selected empty slots can carry the creation context. Check selection before changing a multi-clip scale.
- **Fold to Scale** hides non-scale key rows; **Highlight Scale** marks scale rows purple. Pitch-related MIDI Tools/Pitch and Time Utilities use the active scale. Arpeggiator, Chord, Pitch, Random, and Scale use **Use Current Scale** to express pitch parameters in scale degrees rather than semitones; Auto Shift's Quantizer and Meld's oscillators/filters also support scale awareness. Verify the actual device toggle rather than assuming every device follows the clip.

## Keep playback, signal flow, and automation distinct
| Situation | Correct model and action | Check |
| --- | --- | --- |
| Building a linear song vs launching alternatives | Arrangement places clips on a timeline; Session launches independent clips. Both share tracks and the mixer, but not the same collection of clips. Put alternatives in one Session column and simultaneous parts across tracks in a scene. | One track plays at most one clip, from one view. |
| Arrangement appears to ignore a track | A launched Session clip takes precedence on that track, even while other tracks continue Arrangement playback. Use that track's **Back to Arrangement**, or the global button in Session's Main track/Arrangement's scrub-area top-right. | Confirm the override indication clears and the intended Arrangement clip resumes; pressing Play or switching views is not the recovery. |
| Correct clip, wrong automated value | Manual adjustment outside automation recording overrides that control's envelope. Use **Re-Enable Automation**, or launch a Session clip containing automation. | The control follows its envelope again. This is separate from Back to Arrangement. |
| MIDI notes but no sound | MIDI is control data, not audio. Route it to an instrument or another MIDI destination. Audio clips belong on audio tracks; MIDI clips belong on MIDI tracks. | Verify a receiving instrument and an audio route, not merely visible notes. |
| Reusing a processing setup | Presets store device values; Instrument, Drum, Audio Effect and MIDI Effect Racks preserve multi-device combinations. | Check both device chain and referenced samples after reloading. |

- Audio flows through devices **left to right**, then the mixer. Device-to-device audio connections are stereo even when interface I/O is configured mono. Audio/group/return tracks accept audio effects; returns contain effects, not clips. A MIDI chain runs MIDI effects → instrument → audio effects. A track with neither an instrument nor audio effects outputs MIDI, so its audio mix/send controls disappear.
- Simpler can play one sample chromatically; Impulse assigns different percussion sounds to keys. Load a device by dragging to the intended chain/track, or selecting the target track and using browser Enter. CPU capacity, not an unlimited-device assumption, constrains practical chain size.
- Show mixer sections with **View → Mixer Controls** or **Mixer Config Menu**. Volume/pan shape a track's output; sends feed shared return effects. Crossfader assignments can include multiple tracks and returns, not just two tracks.
- Show **In/Out** under Mixer Controls to choose sources/destinations for external I/O, resampling, submixes, or layering. Monitoring determines when live input is heard. Group Tracks provide submixing; External Audio Effect and External Instrument insert hardware routes into a chain. Verify actual connected hardware and signal return before recording/rendering.
- To record input, choose the destination view, verify routing and arm the track. Selecting several tracks and arming one arms the selection; `Ctrl` / `Cmd` while clicking Arm allows several tracks. With **Exclusive Arm** enabled, inserting an instrument into a new/empty MIDI track auto-arms it. Check other armed tracks before recording.
- **Arrangement Record** records armed inputs and can capture a Session performance into the timeline. Arrangement recording supports takes for later comping; linked tracks support matched edits. Do not confuse an input recording, a performance capture, and a linked edit.
- **Session Record** records new clips in the selected scene's armed tracks; pressing again ends recording and launches them. Launch quantization governs these transitions. For looped MIDI construction, distinguish overdubbing existing notes from **Record Quantization** of new notes; an Impulse or other MIDI-instrument track plus hardware/Computer MIDI Keyboard supplies sound.
- To record control movement, enable **Automation Arm** and Arrangement Record for timeline envelopes, or Automation Arm while recording Session clips. Clip envelopes can automate/modulate mixer and device controls; audio clips also expose pitch/volume envelopes, MIDI clips expose controller envelopes. Unlink an envelope's loop only when it needs a period different from the clip.
- For manual controller assignments, enter **MIDI Map Mode**, select the supported control, send the controller message, then exit mapping mode and verify. Session clips can use a key or chromatic key range. **Key Map Mode** similarly maps computer keys to supported clips/buttons/switches. Mapped MIDI messages are filtered before track recording, so missing recorded notes can be a mapping conflict. Push 1/2/3 dedicated support is distinct from generic mapping.

## Search, filter, and organize browser content
- Show the browser with its Control Bar toggle or `Ctrl+Alt+5` / `Cmd+Option+5`. Browser Config can expose Tuning/Groove Pool and full-height mode. Drag the middle divider for sidebar/content width and the right edge for total width. Dragging the bottom edge closes Info and the open Clip/Device View; **View → Full-Height Browser** instead expands while retaining those views.
- Select a **Collection**, **Library** label, or **Places** location, then search/filter its contents. Use **Content Options** to show columns and file extensions, drag column headers to reorder, and click a header to sort either direction; Name remains visible.
- For a broad search, `Ctrl+F` / `Cmd+F` selects **All** and focuses search. All typed terms must match, not just any one term. Type `#` plus a tag name for tag autocomplete; combine text with filter tags to narrow. Down enters results; Up/Down navigates; Esc clears text and selected tags to show All again.
- Search-field **x** clears text only. **Clear** in Results clears both text and filters; inspect its filter count before concluding an item is absent. Label filter states are remembered when switching labels. Back/Forward arrows or `Ctrl+[` / `Cmd+[` and `Ctrl+]` / `Cmd+]` restore prior searches and navigation states.
- Show/hide Filter View with its toggle. The **Filter View menu** controls visible groups per label, Tag Editor, Quick Tags, and Auto Tags; a group's context menu can hide that group. **Reset Filter Groups to Default** restores the label's default visible groups. Use `Ctrl` / `Cmd`-click to select several tags in one group; do not assume undocumented AND/OR behavior across tags.
- Save a useful text/filter/similarity result with **Add Label** in Results. For a curated custom label, tag the chosen items first, then save that tag search. Label context menus rename factory/custom labels and choose icons; label removal is organizational, not a reason to remove source files.

| Organization mechanism | When to use | Rules |
| --- | --- | --- |
| Factory tags | Discover content by sound/type | Core Library and edition-supplied Packs have descriptive tags; third-party webshop Packs use Sounds tags. Factory item tags/default groups cannot be removed or edited, but extra user tags can be added. |
| Automatic tags | Find analyzed user samples | Background analysis tags user samples up to **60 seconds**; use **Enable Auto Tags** to toggle. Tag Editor can remove an auto tag or convert it to a user tag. VST3 subcategory metadata can supply matching Live category tags. |
| Tag Editor | Structured or batch classification | Open from Filter View menu; check boxes to assign/unassign user tags. Shift-select files first for batch tagging. Fold groups with their arrows; bold fold backgrounds indicate assignments. **Add Tag…** adds within a group; **Add Group…** creates a group that becomes visible once one of its tags is assigned. |
| Nested tags | More detail without many groups | Tag context menu → **Add Subtag in…** nests beneath a parent; parent arrows fold subtags. Creator tags cannot have subtags. Only custom tags/groups can be renamed; do not alter default vocabulary. |
| Quick Tags | Inspect or apply tags with less navigation | **Add…** autocompletes existing tags; a new name offers **Create new tag…**, then an existing/new parent tag or group. Tags display alphabetically. X removes user assignments, not factory tags. In multi-selection, an asterisk means a tag is not shared by every item. Select a tag to see its group in Status Bar; show/hide via **Open Quick Tags**. |
| Collections | Cross-type favorites, including folders | Assign by context menu or keys **1–7**; **0** clears color assignments. Multiple colors are allowed but at most three squares display per item. Rename with context menu or `Ctrl+R` / `Cmd+R`; hover Collections → **Edit**, toggle labels, then **Done**. A newly assigned hidden/unassigned color becomes visible, but an emptied visible label does not auto-hide. |

- Use Library labels deliberately: **All** combines items with devices first; **Sounds** organizes Instrument Racks/presets and Sounds-tagged presets; **Drums** covers drum devices/presets, full Drum Racks, hits, loops/one-shots and Drums-tagged content. **Instruments**, **Audio Effects**, and **MIDI Effects** organize devices/presets and corresponding Racks by device rather than sound.
- **Modulators** includes defaults and Devices→Modulator-tagged devices; **Max for Live** includes its devices/presets and Racks using them; **Plug-Ins** exposes third-party VST/Audio Units. **Clips**, **Samples**, **Grooves**, **Templates**, and **Tunings** expose those artifact types; Tunings includes Core systems and user `.ascl`/`.scl` files. Library → **Edit** changes label visibility; finish with **Done**.
- Navigate with Up/Down, wheel, or `Ctrl+Alt` / `Cmd+Option`-drag scrolling. Left/Right folds folders or moves sidebar/content focus. Opening another folder normally closes earlier ones; hold `Ctrl` / `Cmd` while opening to retain them.

## Preview, compare, and load sounds
- Enable **Preview** at the browser bottom to audition selected samples, Live Clips, and instrument presets; Up/Down changes selection. With Preview disabled, use `Shift+Enter` or Right on the selected item for a preview.
- With **Raw off**, previews loop and, while transport runs, begin at the next bar so they can be compared in context. **Raw on** uses original tempo, does not loop, and disables scrubbing. Scrub the Preview waveform when allowed; a clip saved with Warp off cannot be scrubbed either.
- Adjust preview level with Main's **Preview/Cue Volume**. Separate headphone cueing needs at least four dedicated outputs/two dedicated stereo output pairs and an appropriate cue route; browser preview does not itself guarantee a separate output.
- For local sound comparison, select an eligible file and choose its **Show Similar Files** icon/context command or `Ctrl+Shift+F` / `Cmd+Shift+F`. Samples up to **60 seconds**, instrument presets and drum presets are supported; results compare Core/User Library content and rank most to least similar. The reference appears in search, and remains at the top when saving the result as a custom label.
- Similarity analysis runs in the background for newly discovered user audio; Core Library content is pre-analyzed. Inspect Status Bar progress and **Pause** state before treating absent matches as absence of content. Similar Sample Swapping can use this analysis in **Drum Rack, Simpler, and Drum Sampler**; it is not identical to a text/tag search.
- Drag content onto the intended Session/Arrangement track; empty space right of Session tracks or below Arrangement tracks creates a new track. Double-click/Enter loads into the selected track. In Session, samples become audio clips on audio tracks or load into **Simpler** on MIDI tracks; files can also be dragged from Explorer/Finder. Verify target selection and resulting track/device/clip type before continuing.
- Audio clips reference source samples and apply real-time playback settings without rewriting source audio. Warp changes playback speed independently of pitch to follow Set tempo; inspect the clip's Warp settings rather than assuming every import was analyzed correctly. A MIDI import instead embeds note/controller data and no longer depends on its original `.mid` file.

## Libraries, Packs, and connected sources
- **Places** is location-oriented: Packs, optional Splice/Cloud/Push, User Library, Current Project, and added folders. Use Library Settings to expose connected-source labels; a hidden label does not establish whether an account/device is connected.
- Add discrete content folders via **Add Folder…** or drag a folder from Explorer/Finder into Places. This indexes the existing location, not a copy. Wait for the scanning spinner to finish; avoid whole drives or enormous roots that repeatedly slow indexing. For a grey missing folder, reconnect its drive or use **Locate Folder**. **Remove from Sidebar** forgets the shortcut rather than moving its contents.
- **Packs** shows installed folders, **Updates**, and owned **Available Packs**; installed contents also appear in relevant Library labels. For an explicitly requested installation, inspect size through Content Options, download, then press **Install** after completion. Download icon becomes pause/progress; click pause/resume or use context commands. Multi-select to download/pause/resume several. **Show Downloadable Packs** controls whether Updates/Available are shown; no deletion is needed to hide them.
- Open an installed Pack's **Show Pack Info** context command or Help → **Pack Overview** for creator details and included guidance. Core Library has no Pack Info page. Availability/ownership of a Pack is not evidence that every included device works in the installed edition.
- **User Library** defaults to `\Users\<username>\Documents\Ableton\User Library` on Windows and `~/Music/Ableton/User Library` on macOS. **Location of User Library** can move its configured location; verify accessibility, especially on an external disk. Its separation from installed content supports independent backup. Saved items also appear under relevant Library labels.

| User Library location | Purpose and prerequisite |
| --- | --- |
| **ABL Assets** | Assets of Move/Note Sets already synced through Ableton Cloud. |
| **Chord Banks** | Custom banks for the Stacks MIDI Tool. |
| **Clips** | Saved Live Clips, including MIDI notes/automation and device settings. Samples used by audio clips or sample instruments such as Drum Rack/Sampler are collected according to Collect Files on Export. |
| **Defaults** | Saved track/device/effect and Slicing to MIDI defaults; these govern future instantiation, not arbitrary existing instances. |
| **Grooves** | Custom timing/volume patterns. Extract from an audio/MIDI clip by dragging to Groove Pool or choosing **Extract Groove**. |
| **Presets** | Instrument, Max for Live, MIDI Effect and Audio Effect presets; collect sample dependencies when saving. |
| **Samples** | Dependencies of saved presets/tracks/clips; Recorded/Processed subfolders appear as those sample types are saved. |
| **Templates** | Saved templates and custom default Live Set; created when first needed. |

- Inspect User Library dependencies via **File → Manage Files → Manage User Library**. In **Current Project**, unfold the Set to inspect tracks/clips/devices, Return/Main tracks, and grooves. **Show in Explorer/Finder** reveals its local folder.
- Current Project gains **Backup** after the Project has been saved at least twice. It retains the last **ten** saved Set versions, with bracketed timestamps; older backups go to the system trash. An unsaved Set uses a temporary Project and has no Backup folder. Recover a suitable version into a separately named Set rather than overwriting the only remaining copy.

### Splice: distinguish browsing from account actions
- The Splice label requires Internet. Preview/browse is available before login; adding samples, saving to the Splice library, and Search with Sound require login. If connection is explicitly requested, choose **Login** and compare Live's device-confirmation code with the code in the system browser; the user completes account authentication. **Show Splice** or **Hide from Sidebar** controls visibility.
- Search by text/suggestions, choose **Samples** versus **Packs**, then filter instrument, genre, key, tempo, one-shot/loop and expandable tags. Sort popular/relevant/recent or **Random**/shuffle. Logged-in home browsing offers **Instruments**, **Genres**, and **Cinematic FX** with subcategories; an active category scopes subsequent searches. Navigation arrows restore prior Splice states.
- Free/not-logged-in results use the **Included** filter; the free catalog is approximately **2,500** samples, not a complete catalog search. Entries show pack image/link, one-shot/loop type, name and tags; widening the pane adds Time/Key/BPM. Likes and provider Collections are account features distinct from Live's colored Collections.
- Preview via Play or the sample name. Both one-shots and loops repeat by default; **1 BAR** disables repeated one-shot previews. Loops follow Set tempo unless **1x BPM → Timestretch** is off. Preview controls also set transposition, scale sync and volume. Do not assume preview transformations equal the clip's existing defaults.
- Loading an authorized sample into a Set automatically downloads/licenses it and saves it in the Splice library. Drag to an audio/MIDI track or Sampler, Simpler, Drum Rack, or Impulse; Session also supports Enter/double-click. Resulting clips use **Complex** Warp Mode regardless of the usual Record, Warp & Launch default. Confirm the selected account/content action before loading.
- **Library** Settings chooses `User Library/Samples/Splice` (default), `Current Project/Samples/Splice`, or **Custom Folder**. Splice Library lists previously downloaded samples, Likes, and Collections. For explicitly requested private curation, the heart adds Likes and a sample context menu or Collections page adds/creates collections; inspect the collection's privacy setting. Service Settings exposes subscription/display/log and certified-license information. Do not create shared collections or change subscription state here.
- **Search with Sound** is provider processing that returns **50** suggestions, not Live's local similarity search. Upload/capture procedures and provider sharing are deliberately outside this workflow.

### Existing Cloud and Push content
- Ableton Cloud holds up to **eight** Move/Note Sets. After authorized service sign-in, existing synced Sets appear under Cloud. Live receives these Sets but does not sync developed Live Sets back to Move/Note. Factory/imported samples live in User Library; if missing, reconnect the configured library location. Save further Live work locally with **Collect All and Save**.
- For explicitly requested Push access, use **Push 3 in Standalone Mode** on the computer's Wi-Fi network. Select Push in Places, match its unique device name with Setup → Status on Push, choose **Connect**, and enter the **six-digit** code displayed on Push. Confirm Project folders and its User Library appear; switch away from/back to the Push label to refresh. Context **Disconnect** unpairs; **Show Push** only changes visibility.
- Push-origin Sets can open in Live. Before any separately authorized return-to-Push workflow, use native devices, freeze plug-in tracks, and collect samples into the Project; this is a compatibility preflight, not authorization to transfer files.

## Choose the right saved artifact
| Goal | Artifact/method | Important limitation |
| --- | --- | --- |
| Editable song/version | **Save Live Set**, **Save Live Set As**, or **Save a Copy** (`.als`) | Save As changes name/location of the active document; Save a Copy makes an additional copy. External audio references still need collection. |
| Reusable performance idea and sound | Drag one clip to Current Project/User Library/another Places folder to make a **Live Clip** (`.alc`), then confirm its name | Stores clip/envelope settings and original track devices, but audio remains a sample reference; dependency collection is separate. |
| Reusable sample playback defaults | Audio Clip View title bar → **Save Default Clip** | Stores settings/Warp Markers in the sample's `.asd`; affects future imports, not clips already using it in existing Sets; does not store the device chain. |
| Transfer just MIDI | **Export MIDI Clip** | Standard MIDI data is not a Live Clip's instrument/effect chain. |
| Reusable device setup | Save a preset, or drag a device title bar into the explicit destination's content pane | Choose Current Project for local material or User Library for reusable material; inspect where it landed rather than assuming a default destination. |
| Preconfigured new songs | **Save Live Set As Template…** or **Save Live Set As Default Set…** | Templates reopen as **Untitled.als**. They can include tracks/devices, I/O and key/MIDI mappings. A template context menu's **Set Default Live Set** selects the default. |
| Local Project archive | **Manage Project → Packing → Create Pack** (`.alp`) | Collect dependencies first; packing does not automatically include external files or grant redistribution rights. |

- Create/open with **New Live Set**, **Open Live Set**, **Open Recent Set**, or double-click/Enter on a browser Set. A new save outside an existing Project creates a Project folder; versions of the same work belong in that same Project and share one collected copy of a common sample. Save unrelated work outside that Project.
- A Save As outside the old Project may still reference the old Project's samples; inspect/collect before moving either folder. The Project name is in Live's title bar. Opening any contained Set opens that Project; subfolders are allowed, but reorganized file paths require relinking. Older-major-version Sets require Save As rather than overwriting them in place.
- For session-local recovery, **View → Undo History** or `Ctrl+Alt+Z` / `Cmd+Option+Z` lists newest first. Select an action (or arrow to it and Enter) to restore that point; actions above turn grey and are undone. Selecting a grey action reapplies it and the undone actions below it. History is not saved across closing/reopening; initial create/open cannot be undone. Use file backups for earlier sessions.
- To merge, **drag** a browser Set onto a track title/drop area rather than opening it. Tracks retain Session and Arrangement clips, devices and automation; **return tracks are excluded**. Unfold the source Set to import individual/nested Group Tracks, grooves, or just a **Devices** icon; unfold a track to preview/import its Session clips. Verify return-dependent routing/effects in the destination.
- A Live Clip restores its devices only when dropped into a track with **no clips or devices**, or empty space creating a track. Into an occupied track it keeps clip settings but uses that track's existing devices. Check this before deciding a sound was lost.
- Drag a multi-selection of **Session clips** to Current Project or a user folder to export a new Set; a single clip is the `.alc` case. Tracks/multiple tracks export as `.als`; export individual presets one at a time, retaining their own Live file type. These are different from an audio render.
- For a local archive, open Manage Project, collect its dependencies, then use **Create Pack** and choose a local destination. Lossless compression may reduce size by up to **50%**, depending on content; the original Project is unchanged. To verify restoration, install the `.alp` by double-click, dragging into Live, or **File → Install Pack…**, choose a separate local destination, and inspect every intended Set/dependency before relying on the archive. No publication is implied.

## Repair and collect file dependencies
- **Samples:** native mono/stereo WAV, AIFF, AIFF-C, FLAC, OGG Vorbis; MP3 imports too, and M4A import is macOS-only. Uncompressed samples accept any length/sample rate/bit depth without prior conversion. Disk streaming limits RAM pressure, but many large simultaneous streams can overload disk.
- Compressed imports decode into temporary uncompressed WAVs in the cache's **Decoding** subfolder. File & Folder → Decoding Cache controls **Minimum Free Space**, optional **Maximum Cache Size**, and **Cache Folder** location (normally keep the default). On a cache-full/file-too-large message, inspect these limits and actual disk space; old unused cache entries are managed automatically. Do not confuse this cache with a portable source-file collection.
- `.asd` stores analysis for stretching, long-sample tempo detection, waveform drawing, and optionally default clip settings. It sits beside the source sample, uses its name plus `.asd`, and is hidden in Live's browser; the sample icon's checkmark indicates it exists. A long sample's waveform can remain grey/unplayable while analysis finishes.
- Existing analysis is reused. **Auto-Warp Long Samples off** avoids long-sample analysis; **Create Analysis Files off** avoids writing new analysis files, but needed analysis repeats on imports. It does not erase existing `.asd` files; **Save Default Clip** still creates one. Preserve deliberate default Warp/gain/pitch settings when relocating files.
- Inspect dependencies with **File → Manage Files → Manage Set → View Files**. Expand an entry to see every clip/instrument using it; Location distinguishes missing, User Library, Project and external. A browser file dropped onto an entry, or its **Hot-Swap** control, replaces the reference **everywhere in this Set**, not just the selected clip.
- Replacement retains clip properties and keeps Warp Markers only if the replacement is at least as long as the old sample; a shorter replacement discards them. External **Edit** is destructive, takes the sample offline while engaged, and retains Warp Markers only if length is unchanged; it is sample-only, not a general Max-device editor. Do not perform that edit through this workflow.

### Restore missing media
1. If Status Bar warns and clips/instrument slots say **Offline**, expect silence at those references. Reconnect the expected external drive/User Library first. Open the warning, or **Manage Set → Missing Files → Locate**.
2. For a known exact source, locate it in the browser and drop it on the corresponding missing-file row. Live accepts a supplied file even if it is not the original: verify identity, duration and every affected use before saving.
3. Otherwise expand **Automatic Search**, choose **Set Folder** for a bounded folder/subfolders, and optionally **Search Project** / **Search Library**. Press **Go**. No candidate: choose a better folder or repair manually. One candidate: Live accepts it automatically, so still verify. Multiple candidates: use that row's **Hot-Swap** to inspect/load candidates before choosing.
4. After an intentional within-Project reorganization, use Project context **Manage Project**, Locate missing samples, then **Search Project** plus **Fully Rescan Folders**, Go, and **Collect and Save**. Confirm missing count clears and intended media plays at its expected positions; do not silently substitute a similarly named file.

### Make dependencies portable without indiscriminate copying
- **Collect All and Save** copies chosen external file locations into the Project, putting audio under Samples and devices under Presets. “External” includes Packs, User Library, other Projects and other disk locations. A local Set that can rely on unchanged installed Packs/library need not duplicate them; a portable archive must include dependencies needed at its destination. Multisampled instruments can substantially increase size.
- Alternatively, **Manage Set → External Files** shows counts/sizes by location. **Show** inspects each group; enable **Collect Into Project** where needed, then **Collect and Save**. This confirmation step updates references; seeing the list alone does not collect anything.
- **Collect Files on Export** governs dependency copies when moving clips/presets/tracks into browser folders and when saving sample-based presets to User Library: **Always** (default) copies automatically; **Ask** offers Copy/Don't Copy/Cancel and final name confirmation; **Never** keeps original references. If copying, the destination can gain a Project/subfolders. Export here means a browser artifact, not PCM rendering.
- Apply the same locating/collecting tools to **Manage User Library**, **Manage Project**, or another Project's browser context **Manage Project**. Finish with **Collect and Save** and inspect the resulting references; do not assume repairing one Set repaired all Projects.
- **Manage Project/Manage User Library → Unused Files → Show** is useful for inspection/preview only here. “Unused” means unreferenced within that managed scope; another Project may actively depend on the file. Do not remove it on this evidence alone. Collect other Projects' dependencies before any separately approved cleanup.

## Export audio, MIDI, and video
1. Decide whether the output is an audio render, a MIDI clip, or a reusable Live artifact. For audio/video use **File → Export Audio/Video**, `Ctrl+Shift+R` / `Cmd+Shift+R`. Establish the intended active clips and automation before opening it: rendering captures each track's actual Session/Arrangement playback state, not whichever view is visible.
2. Select a time range in Arrangement first, or explicitly set **Render Start** and **Render Length**; defaults otherwise span the Set. Include a tail in the range for a normal non-looping ending. Confirm the actual range rather than assuming a last clip includes its effect decay.
3. Select the signal, rendering and encoding options below, then export to an intended local destination. Verify output count, filenames, length, channel count, format and intended active clips; audition if tools/user authorization allow, without claiming a listen that did not occur.

| **Rendered Track** | Signal and use |
| --- | --- |
| **Main** | Post-fader Main output, including the currently audible routing/effects. |
| **All Individual Tracks** | Post-fader audio outputs for tracks, Group Tracks, returns and Main; same-length files for alignment. Plain MIDI-only tracks are excluded. A MIDI track with audio effects but no instrument exports silence. |
| **Selected Tracks Only** | Same rules, limited to tracks selected **before** opening the dialog. |
| Individual track name | That track's post-fader output. |

- **Include Return and Main Effects** adds the relevant return signals/Main processing when rendering individual/selected tracks; disabled for Main because those are already in its output. Verify whether the requested stems should contain that processing rather than guessing.
- **Render as Loop** uses two passes: the first primes/calculates effect output; the second writes the fixed-length file with the earlier tail wrapped into its beginning. Use for cyclic output, not as a substitute for an extended ending. **Convert to Mono** makes one channel; **Normalize** raises gain so the highest peak reaches available headroom, not a specified loudness target. **Create Analysis File** creates the accompanying `.asd`.
- **Sample Rate** at or above the Set's In/Out rate renders directly at the selected rate. A lower rate first renders at the Project rate, then downsamples with the SoX resampler. Allow the additional stage to finish; do not treat it as a stalled export.
- **Encode PCM** produces lossless WAV, AIFF or FLAC at **16, 24 or 32** bits as offered by the dialog. For further processing, choose 32-bit and defer dither to the final reduction. Below 32-bit, **Dither Options** are No Dither, Rectangular, Triangular (default), POW-r 1/2/3. Triangular is least prone to further-processing artifacts; Rectangular adds less noise with more quantization error; successive POW-r options push stronger noise toward high frequencies. Dither once; reserve POW-r for the final render, not premaster files.
- **Encode MP3** produces **CBR 320 kbps**, alone or alongside PCM. Its added leading silence can break exact alignment; use PCM for time-aligned exchange. With both PCM and MP3 off, Export is disabled.
- **Create Video** requires video clips in Arrangement **and PCM audio export**; video-only or MP3-only video export is unavailable. Select an installed **Video Encoder** and use **Encoder Settings → Edit** when enabled. Audio renders first, then video; multiple video passes reset the progress bar. Unless encoder settings override it, resolution matches the source; the video contains the rendered audio and is saved beside the audio file.

### Hardware-dependent renders
- External Audio Effect/External Instrument hardware routes make Main and affected individual-track exports **real-time**; unrelated individual tracks still render offline. Live traces routing when export begins. Keep hardware powered, configured and returning the intended signal.
- The real-time dialog waits **10 seconds** to let hardware tails fade. Extend the seconds field or **Restart** the wait if necessary; use **Skip** only when the hardware output is already silent. During rendering, **Restart** repeats the waiting period and pass. **Auto-Restart on drop-outs** retries detected glitches; inspect the attempt count rather than assuming a clean render. Repeated retries call for reducing other CPU-intensive work and checking the signal chain, not accepting a damaged pass.

### MIDI file import and export
- For MIDI import use the browser or **Create → Import MIDI File…**: Arrangement inserts at the Insert Marker; Session inserts into the selected clip slot. Imported MIDI is embedded. Other ways to create MIDI notes are external-controller recording, Draw Mode, MIDI Tools, and audio-to-MIDI conversion. To export one MIDI clip, select it and use **File → Export MIDI Clip**, then choose a destination; verify it separately from any audio-render or Live Clip requirement.
