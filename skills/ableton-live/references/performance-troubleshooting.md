## Scope and preflight
- These are Live UI and physical Push 1/Push 2 procedures, not promises of remote automation support. Confirm available capabilities separately; do not infer Push 3 behavior from these controls.
- Confirm Live version, operating system, connected hardware, selected track/clip, Note versus Session mode, and software focus before acting. Available devices, Packs, conversion commands, Link Audio, and accessibility controls depend on the installed version and entitlements; do not assume an edition includes every option.
- Work on an authorized saved copy before replacement, cropping, conversion, or committing audio. Prefer reversible mute/deactivate, Freeze/Unfreeze, and selection without triggering. Do not change routing, global settings, sync peers, or transport during a performance without authorization.
- In the keyboard atlas, **Mod** means Ctrl on Windows / Cmd on macOS; **AltOpt** means Alt / Option. Literal Ctrl, Cmd, Alt, and Option remain platform-specific. A plus sign joins keys. Focus matters: identical shortcuts act on different objects in different views.

## Push setup and browsing
| Task | Push 1 | Push 2 |
| --- | --- | --- |
| Connect | Connect USB with Live running; automatic detection normally needs no driver or manual control-surface setup. | Connect power and USB, switch on at the rear, and let Live detect it. Live updates may offer firmware updates; handle those separately from a performance. |
| Browse | Browse; columns follow folders. Encoders scroll; Selection Control buttons go up, State Control buttons go down; Shift moves a page. In/Out shifts the visible hierarchy. | Browse; encoders or arrows select folders/items; the two rightmost upper display buttons move through hierarchy levels. Collections exposes tagged items. |
| Load or audition | Right green button loads a preset; left green loads the selected device's default. Amber means already loaded; pressing amber loads the next item. | Load becomes Load Next after loading; Load Previous steps backward. Preview toggles auditions; Shift+Master encoder changes preview level. |
- Browsing is contextual: an instrument selection offers replacements; an effect selection offers effects; an empty MIDI track offers available sounds, instruments, kits, effects, Max for Live devices, and VST/AU plug-ins. Pack/Core Library samples and presets can preview. A missing category may reflect the current target rather than a missing installation.
- Push 1 only shows folders with currently loadable content; sample-only folders appear when browsing an individual Drum Rack pad. Push 2 can browse samples into Simpler or an audio clip slot. Verify the target before loading to avoid replacing a whole kit.
- To replace one drum: enter Device, tap its pad, then select that pad in the display (Push 1: button below its name; Push 2: second upper button, square pad icon). Enter Browse; other pad taps change the replacement target. Push 2 flashes the selected pad.
- Hold Select while tapping a pad to select silently. On Push 2, selecting an expanded Drum Rack's pad with lower display buttons also avoids triggering; left/right moves to neighboring pads.
- Add Track: Push 1 adds MIDI by default; hold it for Audio/MIDI/Return. Push 2 opens a track-type browser with optional device loading. Adding while a member of a Group Track is selected inserts inside that group.
- User Mode disables the built-in integration for custom mappings. For relative encoders use **Relative (2's Comp.)**; slowly turning left while mapping selects this interpretation. Return from User Mode if the normal controls appear disconnected.

## Push pads, beats, and pitch
- For beats, select a MIDI track with a Drum Rack and enter Note. **Push 1 uses Note for layout changes; Push 2 uses Layout.** Do not look for a Push 2 Layout button on Push 1. Confirm the illuminated layout before editing.
| Layout | Use and behavior |
| --- | --- |
| Loop Selector | Lower-left 4×4 plays 16 drums; upper four rows sequence; lower-right 4×4 selects loop pages. |
| 16 Velocities | Lower-right 16 pads choose 16 velocity levels for the selected drum; use for consistent step or real-time dynamics. Accent overrides this on Push 2. |
| 64 pads | Entire 8×8 plays a large kit. Switching layouts does not automatically relocate the 16-pad sequencing bank. |
| Melodic sequencer | Eight rows are pitches, columns are time steps; the scale controls determine available pitches. |
| Melodic Sequencer + 32 Notes | Lower half plays/selects pitches; upper half sequences the selected notes/chords. Select+pad selects without sound. |
- Hold the layout control for momentary alternate/loop controls; Shift+Note (Push 1) or Shift+Layout (Push 2) locks them; press the layout control again to unlock. Melodic loop pads are on the top row; the combined 32-note layout uses the fifth row. Lock state is remembered per track.
- Move a drum bank with Octave Up/Down or the touch strip: 16 pads per move, or single rows while holding Shift. Octave buttons go dark at the available range boundary.
- Drum pad feedback: Push 1 uses bright yellow for loaded, dull yellow for empty, light blue for selected, orange for muted; Push 2 uses track color for loaded, a lighter track color for empty, white for selected, gray for muted. Both use green for playing and dark blue for soloed.
- Select a drum, then tap upper sequencer pads to insert steps; the first insertion starts playback. Default resolution is 1/16; Scene/Grid changes it. Tapping an occupied step removes it; Mute+step deactivates it without removal; Solo+drum isolates that sound. Triplets use only the first six columns; the last two are unavailable.
- Step feedback: moving green is playback, red indicates recording. Push 1 note steps are blue, with darker blue at higher velocity; muted steps are dull yellow and inactive triplet columns may be red. Push 2 uses clip color, brighter for higher velocity, lighter for muted, gray for empty, and unlit inactive triplet columns. In the combined sequencer, selected steps are white.
- For pitched playing, load an instrument and enter Note: default C major, bottom-left C1, successive scale tones to the right, fourths upward. Octave shifts the range. Root pads are blue on Push 1 or track-colored on Push 2; other scale tones are white, played notes green, recorded notes red. Duplicate pitches illuminate together.
- Scales (Push 1) / Scale (Push 2) selects root and scale, only for instrument tracks in Note mode. Push 1 uses Selection/State buttons for root and encoder 1 or the left buttons for scale; Push 2 uses display buttons for root and encoders 2–7 for scale. **In Key** omits outside notes; **Chromatic** includes them unlit. **Fixed** keeps the bottom-left around C (nearest in-key tone if necessary); with Fixed off it follows the root. Scale choices persist with the Set; save a Default Set only if explicitly desired.
- For alternate geometry, Push 1 uses Shift in Scales; Push 2 uses Layout encoder 1 and Direction encoder 8. Choose thirds/fourths vertically or horizontally, or Sequent for a larger range without repeated pitches. These are layout choices, not transposition of existing MIDI.
- In melodic sequencing, Octave buttons/touch strip move the pitch window; Push 2 Shift+Octave moves one scale step and Shift+strip moves octaves. Push 1 supports finer range movement with Shift; its combined 32-note layout uses the same single-note/octave distinction. Read the displayed range; bright strip LEDs show the visible range and dim LEDs mark other ranges containing notes.
- Touch-strip pitch bend/mod wheel is available for real-time instrument playing, not melodic sequencing. Select+tap strip switches the two modes. For drums it selects banks instead.

## Push recording, loops, and note editing
- For real-time Session recording, enable Metronome if needed, press Record, and play. Record again leaves playback running; the next press overdubs. Push 2 shows count-in and playback progress; Shift+Master controls metronome/pre-cue level. Link disables the metronome recording count-in.
- Accent forces played and sequenced notes to full velocity (127). Repeat retriggers a held pad at the Scene/Grid rate; finger pressure varies velocity and Swing adds swing. A quick press latches Accent/Repeat; a hold is momentary. Repeat state/rate is retained per track.
- Hold Quantize to set **Quantize To**, **Quantize Amount**, and **Swing Amount**; leave settings, then press/release to apply. Selected notes are affected, or the whole clip if none are selected; audio quantization affects transients. Quantize+drum affects only that sound. Record Quantize uses encoder 8 on Push 1, encoder 5 plus its upper toggle on Push 2; Push 1 mirrors Live's Edit → Record Quantization setting. Do not expect Push 2 record quantization to apply Swing automatically.
- Fixed Length sets a predetermined duration for new clips; hold it to choose the duration. Without it, Record, New, or Play/Stop ends recording. Turning Fixed Length on during a recording stops capture and loops the last chosen number of bars rather than simply scheduling a later stop.
- Push 2 **Phrase Sync** changes where fixed-length recording starts: normally it begins at the clip start at global launch quantization; Phrase Sync aligns to the current phrase phase. A four-bar phrase started at song bar 7 begins at clip bar 3. Check this before assuming the beginning is missing.
- Push 2 Record follows software focus: Session focus records clips; Arrangement focus toggles Arrangement Recording. Shift+Record reverses that choice. On Push 1, Record+New on an armed MIDI track invokes Capture MIDI.
- Each loop pad represents a sequencer page, not a fixed number of bars. At 1/16, drum/combined sequencing shows two pages totaling two bars; the eight-column melodic sequencer shows two beats. Hold the first loop pad and tap the last for a range; double-tap a page for a one-page loop.
- Single-tap an **inside-loop** page to edit it without following playback. Tapping an **outside-loop** page immediately replaces the loop with that page. Reselect the current loop to restore auto-follow; Push 2 also supports Page Left/Right and holding either Page button to restore follow.
- Loop feedback: outside is unlit; playing is green. Inside-but-hidden is white on Push 1, gray on Push 2; visible-but-not-playing is dull yellow on Push 1, white on Push 2. Push 2 uses red for the recording page. Verify loop duration independently of the visible page.
- In the combined 32-note layout, choose pitches below, then tap a step above to add them. Hold a step to reveal its pitches below; tapping a selected pitch removes that pitch. Holding multiple steps applies note choices to them together. Selected pitches are blue-green on Push 1, a lighter track color on Push 2.
- In Clip mode, hold one or more steps and edit **Nudge**, coarse/fine **Length**, and **Velocity**. Nudge is a percentage offset from the previous grid line; negative is before it. Multi-selection displays ranges. Holding an empty step and changing these controls creates a note. Select+drum plus encoders edits that drum's notes together.
- Duplicate+source step then destination copies notes and their step properties; Duplicate+source loop page then destination layers notes onto existing material. Double (Push 1) / Double Loop (Push 2) duplicates both loop content and length. Verify the destination before adding layers. Delete+loop pad clears that page; it is not required for additive copying.
- Duplicate+source drum then destination replaces destination devices, **not its recorded notes**. Push 2's first two pad encoders set choke group and transposition. Avoid treating pad-copy as pattern-copy.
- Deletion is context-sensitive: Delete alone in Note mode removes the selected clip; Delete+pitch removes that pitch within the loop. Push 1 Delete+drum removes its current-loop notes; Push 2 Delete+drum can remove the pad's devices if it has no notes in the pattern. On Push 2 with Arrangement focused, Delete targets the selected Arrangement clip. Prefer Mute when the intention is merely silence.
- Undo reverses Live's last action, including computer edits; Shift+Undo redoes. Do not assume the undo history belongs only to Push.

## Push workflow, devices, mixing, and automation
| Intent | Procedure and limitation |
| --- | --- |
| Navigate without unintended recording | Left/right selects tracks; MIDI selection implicitly arms them (pink Arm in Live). Push 2 also selects via lower buttons; hold a track button or Record+track button for explicit arm (red in Live), including audio tracks. |
| Choose scene-based versus clip-based work | Push 1: hold User; Push 2: Setup → Workflow. Scene is default: Duplicate captures all playing clips to a new playing scene; New does the same except it prepares an empty slot on the selected track. In Clip workflow, Duplicate copies only the selected clip to the next slot and New prepares only that track; Shift+Duplicate captures the whole playing scene. |
| Navigate vertically in Note mode | Up/down moves one scene and immediately launches it in Scene workflow, or just that track's clip in Clip workflow. Playback inherits the previous clip position like Legato, rather than restarting at its own beginning. |
| Control devices on Push 1 | Device selects parameter control; Selection Control chooses a device, State Control enables/disables it; In/Out accesses banks and Rack chains. Add Effect inserts after the selected device; Shift+Add Effect inserts before. Select the instrument first to insert a MIDI effect before it. |
| Control devices on Push 2 | Device → upper button selects; press again for Edit Mode, then lower buttons choose parameter pages. Upper-left exits Edit Mode. Devices such as Operator can exceed eight pages; lower-right arrow advances, lower-left returns. |
| Add/move/bypass on Push 2 | Add Device browses legal types; an added instrument replaces the current instrument. MIDI effects precede the instrument, audio effects follow. Hold an effect's upper button and turn any encoder to reorder; Mute+upper button bypasses/re-enables. A held Mute can latch; press again to release. |
| Navigate Racks on Push 2 | Select an Instrument/MIDI Effect/Audio Effect Rack, then its upper button toggles device expansion. Selected Rack encoders control Macros; select an enclosed device for its parameters. Hold the Rack's upper button and use lower buttons to choose chains. Drum Rack **device** folding follows Live; it is not toggled directly here. |
| Mix on Push 1 | Volume controls eight track levels; repeated Pan & Send cycles pan then sends. Track controls selected volume, pan, first six sends. Master selects Main; hold a Group Track's Selection Control button to fold/unfold. |
| Mix on Push 2 | Mix toggles Track Mix/Global Mix. Track Mix offers volume/pan/sends or **Input & Output** routing/monitoring; arrows reveal sends beyond six. Global Mix selects one property across eight tracks; arrows move tracks or extra sends, keeping Volume/Pan available. Master toggles Main/previous track. |
| Mix nested tracks/chains on Push 2 | Select then press a Group/Rack track's lower button to expand its mixer contents; arrows reveal off-screen chains. Select+drum jumps to that drum's mixer strip. This mixer expansion differs from Drum Rack device folding. |
- Split Stereo Pan cannot be edited in Push 1 Pan & Send or Push 2 Global Mix: the displayed dial is disabled. Use Track/Track Mix for separate stereo pan sliders. Shift+encoder gives finer adjustment; the far-right/Master encoder controls Main, or Pre-Cue with Shift. Hold a Push 1 display-mode button, or Push 2 Device/Mix/Clip, for a temporary mode; release returns to the previous mode.
- To record parameter movement into a Session clip, enable Automation/Automate (Session Automation Arm), record the changes, then disable it. Push 1 marks automation with a rectangle and overrides with bracketed values; Push 2 uses white versus gray dots. Shift+Automation restores overridden automation.
- For per-step automation, hold steps in Device mode or Push 1 Volume / Push 2 Mix and turn the relevant encoder. The value applies only over those steps; notes need not exist there. Clip mode instead exposes note properties.
- Delete+encoder removes that parameter's automation, **or resets the parameter to default if no automation exists**. Delete+Automation removes all clip automation. Verify override status before considering deletion.
- Push 1 Clip mode edits Loop Start/Position/Length/On, or Clip Start/End when unlooped; audio additionally offers Warp Mode, Detune, Transpose, Gain. Push 2 Clip offers Loop Position/Length/Start Offset, or Start/End when unlooped; Shift gives 1/16 movement. Moving Loop Position carries Start Offset only when both were aligned.
- Push 2 Zoom centers on the last touched position control; audio clips also offer Warp Mode, gain, and transpose (Shift changes cents/Detune). An empty audio slot prompts sample loading. MIDI Crop discards material outside the loop: it is not just a zoom operation.
- Push 2 real-time layouts and Session Clip view fit all MIDI notes on screen. Sequencer view shows a translucent editable page and pitch-range indicators; thicker indicators mean more notes. Move melodic pages horizontally with loop/Page controls, vertically with Octave/strip; drums show only the selected pad. Holding a step zooms its page and highlights its notes.

## Push Session performance and preferences
- Session changes pads to clip launch and Scene/Grid to scene launch; holding Session from Note, or Note from Session, switches momentarily. Select+clip or Select+scene selects without launching. An empty slot on an armed/selected track can record: check slot state before pressing.
- Live's colored Session border shows the controlled 8×8 block. Arrows move one track/scene. Push 1 Shift+arrows moves eight, and Octave moves eight scenes; Push 2 Page moves eight tracks and Octave moves eight scenes. Push 2 Duplicate+clip then destination copies a clip; Duplicate+track selection duplicates a track.
- Push 1 playing clips pulse green/white and recording clips red/white; stopped clips retain clip color. Push 2 playing clips pulse in clip color and recording clips alternate red/clip color. Verify queued launch/record behavior in Live as well as the pads.
- Push 1 Stop/Mute/Solo chooses what State Control buttons do to tracks; Shift+Stop stops all clips. Push 2 Mute/Solo/Stop Clip acts on the selected track, or hold it plus a lower button for another track. Long holds latch these modes; press again to unlock. Locked Stop Clip pulses buttons of playing tracks; Shift+Stop Clip stops all clips.
- For large Sets, Push 1 holds Shift for Session Overview; Push 2 holds Layout, or Shift+Layout locks it. Each overview pad is an 8-track×8-scene block; all pads cover 64×64. Scene buttons choose 64-scene blocks. Selected block is amber on Push 1/white on Push 2, playing blocks green, absent ranges unlit; Push 1 red means no clips playing in that block.
- Push 2 color changes: Shift+track lower button, Shift+Session clip, or Shift+drum opens an outer-ring color palette. Track/clip colors appear in Live; custom drum pad colors persist in the Set but appear only on Push 2.
- Push 1 hold User: raise **Pad Threshold** if accidental or stuck triggers occur; a higher setting needs more force. **Velocity Curve** ranges from Linear to logarithmic; larger Log values give soft playing more dynamic range. **Aftertouch Threshold** ignores lower inputs then rescales the remainder of 0–127; threshold 120 maps 120–127 to 0,18,36,54,72,90,108,127.
- Push 2 Setup: **Pad Sensitivity** 0–10 shifts ease of reaching high velocity; **Pad Gain** especially changes medium strikes; **Pad Dynamics** 0 clusters near the middle, 10 spreads toward extremes. Defaults are 5/5/5; linear response uses Gain 4, Dynamics 7. Judge using the input/output curve and actual playing, not a universal artistic setting.
- Push 2 **Display Light** and **LED Brightness** default to 100%; very dim LEDs can misrepresent colors. Keep color-based diagnostics readable. Both units' Tap Tempo follows beat taps; with **Start Playback with Tap Tempo** enabled, four taps start 4/4 playback. Tempo encoder increments are 1 BPM, or 0.1 with Shift.
- Play/Stop controls transport. Push 1 Shift+Play/Stop resets to 1.1.1 without starting; on Push 2 do this while stopped. Momentary footswitch 1 sustains; footswitch 2 single-taps Record, double-taps New. For inverted pedal behavior use a polarity switch; reconnecting while depressed may also correct polarity.

## Push 2 sampling and conversion
- Load a sample into Simpler before expecting sound; an empty Simpler is silent. Device view exposes waveform and main controls. Short samples may default to one-shot behavior, long ones to looping/warping; inspect rather than assuming. Importing an already warped clip preserves its warp settings/markers.
| Mode | Choose when | Critical controls |
| --- | --- | --- |
| Classic | Pitched, potentially polyphonic playing with ADSR and held looping | Start/End define the working region; S Start/S Length are percentages **inside that region**. At 50%/25%, playback covers its third quarter. S Loop Length works only with Loop enabled. |
| One-Shot | Monophonic hits or short phrases, no looping | Trigger plays despite release; Gate begins Fade Out on release. In Trigger, Fade Out precedes the region's end. Fade In controls onset; Gain sets level; Transpose spans ±48 semitones. Shift+Play/Stop can immediately stop a triggered sample. |
| Slicing | Play or sequence segments of a break | Slice By chooses Transient, Beat, Region, or Manual; playback uses drum-style layouts rather than pitched layouts. |
- Zoom follows the last touched sample-position control. Press Simpler's upper button for Edit Mode, lower buttons for parameter banks, upper buttons for toggles; press its upper button again to leave. **Warp as…** fits Start–End to a chosen bar count; **÷2** doubles playback speed and **×2** halves it by changing interpreted duration.
- Classic/One-Shot offer Crop and Reverse; both create a processed copy, not an overwrite of the original sample. Slicing also offers Reverse and warp controls. Confirm which working region is affected before processing.
- For legato repitching without restart: Edit → Global → **Glide Mode: Glide**; Classic also requires **Voices: 1** (One-Shot is already mono). Play overlapping notes. Enable Warp to preserve timing; compare Warp modes deliberately, since transposition changes timbre and Complex Pro costs more processing.
- Transient slicing uses **Sensitivity**, up to 64 slices; Beat uses musical **Division**; Region uses **Regions** equal-time divisions. Manual creates no automatic boundaries: enable **Pad Slicing**, play a slice, tap empty pads at wanted boundaries, then disable Pad Slicing. Later slices shift upward as new boundaries are inserted.
- Slice pads fill groups of four left-to-right from bottom-left upward through the left half, then bottom-right upward through the right half. Layout cycles 64 pads, Loop Selector, and 16 Velocities. **Playback: Mono** allows one slice; **Poly** overlaps; **Through** is mono but continues to the end of the region. Trigger/Gate still determines response to release.
- Select a slice, Zoom, then **Nudge** its boundary; Shift provides very fine movement. **Split Slice** inserts a midpoint boundary. Delete+slice removes the slice, not the source sample. Check pad assignments after manual insertion, deletion, or splitting.
| Convert target | Result to inspect before continuing |
| --- | --- |
| Classic/One-Shot Simpler | New MIDI track, Drum Rack with a Simpler copy on its first pad; other original-track devices are copied too. |
| Slicing Simpler | Replaces that Simpler on the same track with a Drum Rack, one slice per pad. |
| Selected Drum Rack pad | New MIDI track containing that pad's devices. |
| Audio clip | Choose new Simpler track or Drum Rack with Simpler on first pad; warp data and other devices carry over. Harmony/Melody/Drums audio-to-MIDI are separate conversion choices, subject to availability. |

## Synchronizing a performance
| Situation | Method and constraints |
| --- | --- |
| Cooperative apps/devices on one network | Link shares beat, tempo, and phase; no permanent leader. Start/stop remains independent unless every intended peer enables **Start Stop Sync**. |
| Also transport audio between supported peers | Link Audio requires both Link and Audio enabled. Other applications may send only; Live/Push can send and receive. |
| Follow a drummer or turntables without a digital clock | Tempo Follower analyzes rhythmic external audio; use a clear rhythm rather than assuming arbitrary audio yields a stable tempo. |
| Follow or drive a drum machine/sequencer | MIDI Clock carries tempo and song-position information; Live can send or receive. |
| Align to film/tape seconds and frames | MIDI Timecode positions the Arrangement; Live receives only, not sends. Set tempo manually: timecode has neither meter nor tempo-change information. |
- **Link:** connect to the same stable wired/Wi-Fi network, enable the Control Bar Link toggle, and verify peer count. Settings → Link or **Configure Link…** controls visibility and options. When stopped with peers present, the Arrangement Position progress bar shows the launch-quantization wait; starting waits for its completion.
- The first Link participant establishes initial tempo; afterward the last tempo change wins, overriding tempo automation. Participants can join/leave independently. Recording count-in is unavailable with Link. Link can share tempo derived from Tempo Follower or incoming MIDI sync.
- **Link Audio:** enable Audio on intended peers, set an identifiable Name, inspect peer status/buffer amounts, and adjust **Latency** for incoming buffering. **Sync to Incoming Audio** delays Live's playback by that latency to align it with monitored incoming audio; enable it on **only one** session participant.
- Receive Link Audio on an audio track: Input Type = peer, Input Channel = source track; monitor In, or arm and use In/Auto. Arm to record. Tracks with audio output are streamable to peers; do not enable network audio or expose tracks without authorization. For missing input, first confirm both toggles, peer visibility, source channel, arm, and monitoring.
- **Tempo Follower:** Settings → Tempo & MIDI → Tempo Follower → Input Channel (Ext. In), choose the interface input carrying the rhythmic source; show the toggle, then enable **Follow**. Hiding the button stops the follower. Gray means its configured input cannot be connected; repair device/channel selection before diagnosing rhythm detection.
- Tempo Follower and incoming External Sync are mutually exclusive. Follower may still drive outgoing MIDI Clock; it cannot receive MIDI Clock while active.
- **MIDI host:** connect a receiving device configured for clock, enable its output Sync destination in Tempo & MIDI, and verify the lower EXT-adjacent LED flashes. **MIDI follower:** enable input Sync for the sending device, then EXT/Options → External Sync; the upper LED confirms usable incoming sync.
- Incoming song-position pointers move Live; with Arrangement Loop on, incoming positions wrap within that loop. Disable looping only when authorized if full-song position following is required.
- For timecode, expand the MIDI port, choose **MIDI Sync Type: MIDI Timecode**, select frame rate or **SMPTE All** auto-detection, and set **MIDI Timecode Offset** as Arrangement start time. Display format is separately selected via Options → Time Ruler Format.
- If clock timing is consistently offset, play clear percussive patterns in both systems and adjust that port's **Sync Delay** while comparing their output. Recheck after changes; do not use a fixed offset to conceal random jitter.

## CPU, disk, and freezing
- Diagnose the **Overload indicator**, not just audible clicks: **Disk** means storage could not keep up; **CPU** appears only after enabling **Warn on Current CPU Overload** (same state as **CPU Overload Indicator** in its context menu). CPU warnings are off by default, so absence of “CPU” is not proof of headroom.
- Live's CPU meter is audio-buffer work time divided by buffer playback time, not the operating system's total CPU percentage. 50% means computation takes half the buffer duration; over 100% misses the deadline. UI work is excluded, but other applications/OS scheduling can interrupt audio work.
- Enable **Current** to see peaks and **Average** for sustained load; **Meter Text Shows** chooses which percentage is printed. With both enabled, the lighter meter is average and darker is current. Compare the same workload before and after a change.
- Enable mixer **Performance Impact** through Show/Hide Mixer Config or View → Mixer Controls. Six rectangles show each track's relative impact; inspect high-impact tracks, temporarily deactivate suspect devices, or freeze them. Empty/no-input effects usually idle, but tails continue processing until finished; low idle load does not predict worst-case load.
- Rehearse the intended peak workload, including simultaneous clips/devices and tails, with Current comfortably below 100%. CPU clock, architecture, cache, bus bandwidth, thermal throttling, and other applications can affect results; a multicore CPU alone does not guarantee headroom.
- Disable genuinely unused audio channels in Audio Settings → Input/Output Config to reduce constant transfer load. Do this between performances: some drivers audibly glitch when configuration changes.
- Disk traffic roughly follows simultaneous audio channels; stereo costs more than mono. If Disk overloads, test clip **RAM Mode** when memory permits. Consolidating many audio tracks through an authorized Group bounce can reduce simultaneous file reads; this is a commitment, not the first reversible diagnosis.
- Freeze a selected clip-bearing track using Edit/context → **Freeze Track** or Mod+AltOpt+Shift+F. It renders Session and Arrangement clips to audio, reducing repeated device/clip calculations. Group, Return, and Main tracks cannot freeze; Group tracks can instead be bounced to audio when committing is intended.
- External Instrument/External Audio Effect routed to hardware require real-time freezing; allow the complete hardware performance and inspect the rendering options. Do not assume an offline operation or disconnect hardware mid-render.
- Frozen device/clip settings are locked; **Unfreeze Track** restores editing. Volume/pan/sends, mixer automation/envelopes, launch recording, clip cut/copy/paste/duplicate/trim/consolidate, and scene creation/movement/duplication remain possible. Frozen MIDI clips can be dragged to audio tracks.
- Arrangement freeze tails appear as adjacent crosshatched temporary clips; move them together with their source clip. Editing frozen content can sound different after unfreezing because live delay/reverb responses are then recalculated. Frozen rendered tails stop abruptly when stopped, unlike running effect tails.
- Session freeze includes **two loop cycles only**; longer unlinked envelopes/tails may change or be cut. Arrangement parameter automation is rendered; Session freeze uses Arrangement parameter values at **1.1.1**, while Session behavior otherwise supersedes Arrangement automation. Random device decisions, such as Beat Repeat Chance, become a fixed recorded outcome.
- Frozen playback uses Warp in Beats mode; tempo changes can therefore alter it. Freeze files are 32-bit, stored under the Project's `Samples/Processed/Freeze`, or the Temporary Folder before saving. Hardware-device freeze files are discarded immediately on Unfreeze; preserve an authorized render first if it must survive.
- Dragging a frozen clip to empty drop space makes a new frozen track; an Arrangement partial selection transfers only that portion. Frozen tracks can play on a less powerful computer or one missing their devices, but those computers cannot necessarily recreate the unfrozen processing.

## Preserving signal integrity
- Distinguish numerical identity from audible quality: a useful effect, fade, gain change, or warp intentionally changes samples. Do not promise a null result for an entire chain merely because one operation is transparent, or treat lack of a null as proof of an audible defect.
| Operation or goal | Condition / consequence |
| --- | --- |
| Neutral playback/export | Match file, interface/project, and export sample rates; no transposition, stretching, gain/effects, groove, or fades. Undithered export at the same/higher bit depth preserves unprocessed samples; lowering depth introduces quantization distortion. |
| Warped but unstretched playback | Beats, Tones, Texture, and Re-Pitch can be neutral at original tempo; returning to that tempo restores unstretched playback. Complex/Complex Pro are never neutral, even there. Tempo automation with Beats transient preservation can artifact; consider Preserve 1/16 or Re-Pitch where appropriate. |
| Summing and routing | Single mix points use 64-bit summing; surrounding internal processing is 32-bit, so multiple summing stages can introduce tiny rounding differences. Routing itself preserves the tapped signal, not necessarily the post-effects/mixer signal you had been hearing; this includes Impulse individual-slot outputs. |
| External recording | Recording bit depth must be at least the A/D converter's to preserve its delivered signal. A lower setting loses precision; higher bit depth does not undo converter limitations. |
| Internal recording | Use 32-bit for instruments/effected audio. Unprocessed lower-depth material can remain neutral at its own depth; padding a 16-bit source to 32-bit adds no information. |
| Freeze, bypass, split | Freeze has the exceptions above. Bypassed native/VST/AU effects remove processing, but intrinsic delay such as Compressor Lookahead remains for delay compensation. Splitting otherwise-neutral clips is sample-accurate and seamless; it does not alter sample data. |
| Rate conversion and pitch | Different playback/export rates and transposition are non-neutral. Choose a project rate early; offline-convert mismatched material rather than repeatedly converting during playback. Export conversion uses SoX resampling. |
| Gain and dither | Volume automation changes gain; its curve updates each sample. Any gain processing makes the signal 32-bit internally. Keep intermediate renders at 32-bit without dither; dither once at final lower-bit-depth delivery, not repeatedly between stages. |
| Consolidate | New audio is normalized with compensating clip gain and uses configured sample rate/bit depth. Equal playback loudness does not mean identical file samples. |
| Fades, pan, groove | Edge declick fades can be up to 4 ms; Session Fade and editable Arrangement fades/crossfades also change samples. Constant-power pan is 0 dB center and +3 dB at either extreme; Utility Width can narrow stereo before extreme pan. Grooves move Warp Markers and are non-neutral even at original tempo. |
- For an identity-sensitive transfer, disable unnecessary Warp/Fade, leave Transpose/Detune unchanged, match rates, and preserve depth. These restrictions sacrifice stretching/synchronization; do not impose them on creative work. Select recording quality that the actual interface/computer supports, rather than changing sample rate mid-project.
- Verify with matched-routing, aligned rendered comparisons or cancellation tests when identity matters. No playback, listening, rendering, or null test is implied by these procedures; effects, random devices, tails, pan, dither, and mismatched ranges must be accounted for first.

## Diagnosing MIDI timing
- First classify the path: **recording** stores incoming notes/CC; **playback** sends stored data to hardware or an internal instrument; **playthrough** routes live input through Live to sound. Separate consistent **latency** from variable **jitter**; jitter is harder to compensate by playing earlier or shifting a clip.
- Live relies on driver timestamps for recording and schedules outgoing MIDI where possible. Windows MME cannot process outgoing timestamps, so Live schedules those events internally. External serial MIDI cannot transmit simultaneous events simultaneously; dense chords/CC, slow legacy keyboard scanning, extra devices, or inaccurate drivers can add skew outside Live's control.
- When monitoring during recording, Live adds audio-buffer-related delay to timestamps so stored notes reflect what was heard through Live, not merely physical keypress time. If listening directly to a hardware synthesizer, or recording another MIDI device's generated sequence, turn track monitoring off; enable it only for actual playthrough (including monitored External Instrument use).
- For responsiveness, choose the lowest **stable** audio buffer and a reliable MIDI interface/current compatible driver. Change one factor at a time, then re-record the same pattern. High-load audio dropouts can corrupt playthrough timing/sound while MIDI events still record; replay after recovery before assuming the stored clip is damaged.
- Do not promise sample-accurate external MIDI. Illustrative tests at about 50% CPU, 44.1/96 kHz, three buffer sizes, three anonymous interfaces, and both operating systems covered 36 configurations; outgoing results were comparable to incoming. These are hardware-dependent historical observations, not thresholds for a new system:
| Interface | Windows observed jitter | macOS observed jitter |
| --- | --- | --- |
| A | Maximum ±4 ms; most around ±1 ms. | Usually max ±5 ms; at 44.1 kHz/1152 samples a reported spread of ±4–11 ms. |
| B | Usually max ±3–4 ms; rare ±5 ms at 96 kHz/1024, ±6 ms at 44.1 kHz/512; most ±1 ms. | Usually max ±4–5 ms; 44.1 kHz/1152 had a reported ±2–11 ms spread. |
| C | Usually max ±5 ms; rare ±6–8 ms at 96 kHz/512 and ±10 ms at 44.1 kHz/1024; most ±1 ms. | Maximum ±1 ms; most events had none. |
- For rigorous input measurement, a zero-latency splitter can send the same MIDI source to Live's MIDI recording and a MIDI-electrical-signal-to-audio reference recorder; compare event times. An ordinary synthesizer's audio is not a zero-latency reference. Without calibrated reference hardware, report relative timing and limitations, not exact absolute accuracy.

## Accessible navigation and editing
- Live 12 supports native macOS/Windows accessibility and high-contrast themes, but support is incomplete: browser filters/tagging, MPE editing, Max for Live, some third-party plug-ins, Wavetable's Modulation Matrix, advanced Operator parameters, and audio-clip fade editing may need an alternative interaction path. Controller-script screen-reader support also varies.
- Enable **Use Tab Key to Move Focus** in Navigate or Display & Input when using Tab navigation. Tab/Shift+Tab moves forward/back; **Wrap Tab Navigation** cycles at area boundaries. Without this mode Tab switches Session/Arrangement. **Move Clips with Arrow Keys** defaults on; off makes left/right collapse time selection to its start/end instead of moving content.
- Focus views with AltOpt+0…8: Control Bar, Session, Arrangement, Clip editor, Device, Browser, Groove Pool, Learn, selected Clip panel respectively. AltOpt+Shift+P focuses Clip panels. Control Bar remembers its last control. Next/Previous Neighbor is Ctrl+Tab / Ctrl+Shift+Tab on Windows, Option+Tab / Option+Shift+Tab on macOS; in mixers it moves to the same control on the adjacent track.
- Settings opens with Mod+comma. Tab/Shift+Tab works there regardless of navigation preference; arrows change values/options, Enter toggles, Esc closes. Neighbor shortcuts switch Settings pages; Shift+Tab from a page's first control returns to the page chooser. A UI-language change needs restart.
- Windows menus use Alt+initial (Alt+O Options, Alt+N Navigate); macOS VoiceOver uses VO+M then the initial. Options → Accessibility controls **Speak Menu Commands**, **Speak Minimum and Maximum Slider Values**, and **Speak Time in Seconds**. Enable help descriptions in the screen reader, or VoiceOver Utility verbosity; VO+Shift+H requests help text.
- Accessible setup: Settings → Audio, Tab through driver/input/output controls; macOS uses CoreAudio devices, Windows driver configuration may live in the driver's application. MIDI/control-surface settings offer six Control Surface slots with separate input/output ports; tab naming may be Tempo & MIDI or Link, Tempo & MIDI depending on the installed build.
- Session: arrows navigate titles/slots/scenes; Enter launches selected clip/scene at launch quantization; Mod+Shift+M creates MIDI in a MIDI slot. Return-track slots cannot contain clips. Tab reaches mixer controls; Esc returns to the track title. View → Mixer Controls exposes hidden routing, track options, crossfader, and performance fields.
- Arrangement: up/down selects tracks, left/right moves time or selected content according to preferences/grid; Shift extends selection. Ctrl+left/right (Windows) or Option+left/right (macOS) reaches clip edges/locators. Add a locator by positioning then focusing **Set Locator** and pressing Enter; Tab moves between locators. At a clip edge, Enter enters resizing, arrows adjust, Enter commits, Esc cancels.
- Clip: open via Mod+AltOpt+3, then AltOpt+3 focuses its editor. Enable **MIDI Note Editor Preview** to hear added/selected/moved notes. Select time with Shift+arrows, Enter selects notes in that span; arrows move notes, Shift+up/down transposes octaves, Shift+left/right changes length. Mod+up/down changes velocity; Mod+AltOpt+up/down changes chance. Verify installed Windows note-navigation shortcuts via menus before relying on Alt versus Ctrl variants.
- Audio editor: time selection and marker movement use arrows; Mod+I inserts/selects Warp Marker and Mod+Shift+I inserts transient. Device view presents devices as groups: left/right changes device, Tab enters controls. Groove Pool uses Tab between parameters and up/down for values; Learn contains tutorials.
- Browser: Mod+F focuses search and selects All. Down enters results; Tab moves through filter toggles/sidebar/content, left/right crosses sidebar/content or collapses/expands folders, up/down changes items, Shift extends selection. Browser File Preview enables automatic audition; right arrow can audition even with it disabled. Do not mistake keyboard reachability of filters for full screen-reader support.
- For automation/modulation in Arrangement lanes or Clip Envelopes: arrows move the insert marker and expose the value; Enter creates/selects a breakpoint. Move it with arrows or enter a numeric value; Enter commits/deselects, Esc cancels/deselects. Selected points pulse; Tab/Shift+Tab selects the next/previous point; AltOpt+left/right jumps boundaries. Delete removes a selected point. Undo briefly highlights the affected point.
- AltOpt+up/down cycles existing device automation envelopes on an Arrangement track; AltOpt+Shift+up/down includes unautomated parameters. AltOpt+click selects a breakpoint and positions the insert marker. Confirm the active envelope and value before typing.

## Verification and recovery
1. Confirm hardware model, view, selected object, arm/monitor state, and saved work before any performance edit. Read the display or accessible feedback after each state-changing action; a layout change can change what the same pad/key does.
2. For silence, inspect transport, clip state, track/device mute, routing, monitoring, empty Simpler/pad, and User Mode before changing global audio settings. For timing drift, identify clock authority and whether the error is fixed offset, phase/loop wrapping, or jitter.
3. For overload, reproduce the peak workload, distinguish Disk from CPU, and compare Current plus per-track impact before/after one reversible change. Recheck frozen tails, two-cycle Session limits, and automation at the intended performance tempo.
4. For surprising edits, cancel unfinished value/edge/breakpoint edits with Esc; inspect Undo before invoking it because actions from all interfaces share history. Restore automation with Shift+Automation rather than deleting it; unfreeze rather than replacing the source merely to edit it.
5. Report what was actually observed: UI state, measured load/timing, resulting clip/device/routing, or rendered comparison. Explicitly label unavailable hardware, inaccessible controls, untested shortcut variants, and unperformed listening/rendering tests.
