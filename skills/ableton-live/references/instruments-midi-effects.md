## Choose and verify
These are Live UI procedures, not declarations of extension or automation support. Check the installed Live version, licensed edition, device availability, and visible controls before acting; exact minimum versions and edition entitlements are not established here. Use only capabilities actually exposed by the current integration; otherwise perform a verified UI operation or explain the limitation.

| Need | Choose | Important boundary |
| --- | --- | --- |
| Change notes, timing, dynamics, or control messages | MIDI effects | They transform MIDI; verify the receiving instrument or hardware too. |
| Dual-path modeled subtractive synthesis / compact subtractive synthesis | Analog / Drift | Analog has independent filters/amps; Drift emphasizes direct controls and per-voice variation. |
| Mallet/object / electric-piano / string modeling | Collision / Electric / Tension | Interacting physical parameters can produce silence or abrupt level changes. |
| Layered macro synthesis / detailed FM-additive synthesis / moving wavetable timbres | Meld / Operator / Wavetable | Different modulation, scale, voice, and CPU rules apply. |
| A Drum Rack one-shot / eight-slot drum kit | Drum Sampler / Impulse | Impulse parameter edits take effect on the next note, not mid-note. |
| Warp or slice one sample / map multiple samples by key and velocity | Simpler / Sampler | Sampler does not preserve Simpler's warping or slicing behavior. |
| Send MIDI and return hardware or multitimbral plug-in audio | External Instrument | It is a routing utility, not a sound generator. |

**Verification loop:** choose a known note/short phrase, confirm track monitoring or arming and the intended destination, then change one control group at a time. Check note output/visible activity, output meters, note release, pitch range, and CPU; distinguish an observed UI setting from an auditioned result. For silence, check activators, note/range gates, modulation depth, sample/voice selection, and audio return before increasing gain. Compare short, held, repeated, overlapping, low/high, and soft/hard notes when those dimensions matter. Keep output low while exploring resonators, feedback, drive, or unnormalized harmonics. These are proposed checks, not claims of completed Live tests.

## Shared filter and envelope controls
- **ADSR:** Attack reaches Peak, Decay reaches Sustain, Sustain lasts until release unless a special mode bypasses it, and Release reaches the end level. Distinguish time controls from level controls. A modulation envelope needs a destination and nonzero amount; an enabled generator alone is insufficient.
- **Operator, Sampler, Simpler, Wavetable filter choice:** low-pass, high-pass, band-pass, notch, or Morph; 12 or 24 dB/octave. Clean is the efficient neutral circuit; OSR is a state-variable circuit with hard-clipped resonance. Both support every filter type. MS2 (Sallen-Key, soft-limited resonance), SMP (hybrid), and PRD (ladder, no explicit resonance limiter) support low/high-pass only. Non-Clean low/high/band-pass configurations expose input Drive. Frequency locates the filter; Resonance emphasizes its neighborhood. Morph travels low-pass → band-pass → high-pass → notch → low-pass; Operator/Sampler/Simpler provide context-menu snapping to those shapes.
- **Envelope slopes where available:** positive bends the segment toward a fast beginning and slow ending; negative holds back then moves rapidly; zero is linear. Do not transfer one device's Trigger, Loop, legato, or retrigger behavior to another. Verify them with held and released notes.

## Arpeggiator
- Choose a Style, inspect its pattern display, then set Rate in synchronized beat divisions or free milliseconds. Up/Down/Converge/Diverge order pitches; Play Order follows performance order; Chord Trigger repeats the entire chord. Random redraws continually; Random Other exhausts the incoming notes before repeating one; Random Once repeats one random order until the input changes. Previous/Next Style Pattern cycle choices.
- Set Distance in semitones or scale degrees and Steps as the number of successive transpositions **after** the original pass: +12 st, Steps 2 gives original, +12, +24. Select Root/Scale locally or enable Use Current Scale; the latter follows the clip and disables the local choosers. Gate is a percentage of Rate; above 100% overlaps notes. Pattern Offset rotates the note order, not the timing grid; offset 1 starts with the second note.
- Hold sustains after key release; while holding the initial keys, add keys to extend the held collection, or play an included note again to remove it. Groove selects swing; intensity follows Global Groove Amount in the Groove Pool/Control Bar.
- Retrigger Off never restarts, Note restarts on a new note, and Beat restarts at Interval; check the retrigger LED. Repeats defaults to infinity; finite repeats plus Beat retrigger can create gaps. Enable Velocity, set Target and Decay for a velocity trajectory, and enable its Retrigger switch if that trajectory should restart with the pattern. If repetition unexpectedly stops, inspect Repeats and Retrigger before changing notes.

## CC Control
- For hardware parameter control, select the receiving port/channel first. Mod Wheel sends modulation, Pitch Bend sends signed bend, and Pressure sends channel aftertouch. Custom A is an on/off or min/max button, normally suited to CC 64 sustain; assign its CC Type Chooser deliberately. Custom B–M are twelve renamable assignable dials; their names/assignments appear on Push and can be stored in presets.
- Switch title-bar banks 1–8 / 9–16 to reach all controls. Use Learn with incoming controller data to identify/assign a CC, then leave learning when complete. Automate the device controls or adjust them live. Send transmits **all current** CC values: use it only when that full receiver-state update is intended. Existing CC automation and device-generated messages merge; competing streams are not automatically overridden. Verify a single intended control at the receiver before sending the whole state.

## Chord
- Shift 1–6 add up to six notes to each incoming root, each within ±36 semitones; +4/+7 gives a major triad. Repeated Shift pitches are deactivated rather than doubled. For Learn, hold the root first, add the other keys without releasing it, then disable Learn; the root itself does not occupy a Shift slot. LEDs indicate generated notes.
- Velocity per added note is relative to input, 1–200% (100% matches); Chance is 0–100% per added note. Use both when variation must affect balance and occurrence independently. Use Current Scale changes pitch shifts to scale degrees.
- Strum adds up to 400 ms between notes. Positive follows root then Shift 1–6; negative reverses that **slot order**, not necessarily ascending pitch. Tension positive accelerates from a slow start, negative decelerates; Crescendo positive raises successive velocities, negative lowers them. The context option Play Duplicate Notes When Strumming permits duplicate strummed notes.
- Send Per Note Events to Generated Notes passes MPE to the added notes; with scale awareness, per-note bends follow the clip scale. Verify generated notes and expression separately; a sounding root does not prove its added notes receive expression.

## Note Length
- Choose Note On to replace input duration with Length × Gate (100% unchanged, 200% double, 50% half); Time Mode selects milliseconds or synchronized beats. Choose Note Off for release-triggered output: it starts when the original note ends, then runs for the configured duration.
- In Note Off mode, Release Velocity blends Note On/Off velocities; leave it at 0% for a controller without release velocity. Decay Time starts reducing velocity at the original Note On and uses the remaining value at Note Off. Key Scale positive lengthens below C3 and shortens above; negative reverses this.
- Latch overrides Gate/Length. With Note On, notes sustain until the next Note On. With Note Off, triggering depends on all keys/sustain being released and a new Note Off arriving; Release Velocity, Decay Time, and Key Scale are also disabled. If a release-triggered note seems absent, check sustain state and velocity decay rather than shortening Length blindly.

## Pitch
- Transpose by ±128 semitones or, with Use Current Scale, ±30 scale degrees. Step Up/Down change Pitch by Step Width, 1–48 semitones or 1–30 scale degrees; these controls can receive MIDI/key mappings.
- Lowest/Range define allowed pitches. Block suppresses out-of-range notes (watch its LED); Fold transposes them into range; Limit clamps them to the lowest/highest boundary. Verify edge pitches before using this as a playable-range constraint; Scale's range controls behave differently.

## Random
- Chance sets the probability of pitch change. Choices (1–24) sets possible offsets and Interval sets their spacing; their product determines the excursion range. With Random/Add, Chance 50%, Choices 1, Interval 12 yields unchanged notes or octave-up notes; Choices 12, Interval 1 instead offers intervening semitones.
- Sign Add goes upward, Sub downward, Bi either way. Random chooses unordered offsets; Alt uses a fixed round-robin sequence, with 100% Chance advancing and 0% preserving input. Do not assume its cycle length from the product alone; verify the generated sequence. The +/0/− LEDs show direction. Use Current Scale constrains the generated pitches to the clip scale.

## Scale
- Select Base and Scale Name, or enable Use Current Scale to inherit and lock both to the clip. In the note matrix, columns are input and rows output; mapping starts at the bottom-left root. Choose User to edit mappings: move active cells to redirect notes; removing a mapping suppresses that input rather than passing it unchanged.
- Transpose is ±36 semitones. User mode's Fold chooses the nearer octave when a mapping would move farther than six semitones (C3→A3 becomes C3→A2). Lowest/Range restrict **where remapping/transposition applies**; outside notes remain unchanged. Example: Lowest C2, Range +36 affects C2–B4; +7 st transposes only that region. Check boundary notes as well as in-scale notes.

## Velocity
- Choose Operation: note-on Velocity, release Rel. Vel., or both. Musical note velocities span 1–127; Lowest/Range define the input window and Out Low/Out Hi the output range. The grid's horizontal axis is input, vertical is output. For a transparent starting curve use Lowest/Out Low 0 and Range/Out Hi 127.
- Clip confines out-of-range input, Gate removes it (LED flashes), Fixed outputs Out Hi regardless of input. Random adds bipolar variation limited by the output range; e.g. ±50 stays within Out Low 60 / Out Hi 127. Positive Drive favors loud values and negative favors soft; positive Compand expands toward extremes, negative compresses toward the middle. Verify that Gate has not removed quiet notes and that the receiving instrument actually responds to the selected velocity type.

## Analog
- **Build the route first:** two oscillators plus Noise feed two filters, each with an amplifier. Oscillator/noise F1/F2 balances their inputs; Fil 1's To F2 adds serial feeding. Global Quick Routing: upper-left gives separate oscillator/filter/amp paths; upper-right splits both sources across both paths; lower-left uses Filter/Amp 1 only; lower-right sends both sources through Filter 1→Filter 2/Amp 2. It changes routing, not oscillator level/tuning/waveform. Select a shell section to expose its additional display controls; Noise controls remain in the shell.
- **Oscillators:** enable Osc 1/2 and set level, Shape (sine/saw/rectangle/white noise), Octave, Semi, and Detune (±300 cents). Rectangle Width reaches a square at 100%; use its corresponding enabled LFO for pulse-width modulation. Pitch Mod LFO also needs that LFO on. Key 100% tracks equal-tempered notes, 0% ignores pitch, with C3 unchanged by scaling. Pitch Env Initial/Time creates a starting-pitch ramp to the final pitch.
- Sub/Sync Mode Sub adds an octave-down square for saw/rectangle or sine for sine; white noise disables the sub. Sync instead resets the oscillator from an internal oscillator: Ratio 0% matches frequencies and has no sync effect; increasing Ratio changes harmonics. Noise's Color adjusts its own 6 dB/octave low-pass before F1/F2 routing.
- **Filters/amplifiers:** choose 2nd/4th-order low/high/band-pass, notch, or formant; formant Reso selects vowels. Fil 2 Follow tracks Fil 1's cutoff including its modulation, turning Fil 2 Freq into an offset. Set Freq Mod/Res Mod from LFO, Key, or envelope; Drive offers Off, three symmetric, and three asymmetric saturation strengths. Amp 1/2 Level and Pan follow the filters; their display adds LFO/key/envelope modulation. Key-to-level pivots around C3.
- **Four filter/amp envelopes:** ADSR plus Att < Vel (higher velocity shortens attack), Env < Vel (level sensitivity), S.Time (sustain falls while held), and linear/exponential Slope. Sustain minimum removes sustain, maximum removes decay. Legato reuses the current envelope on overlapping notes; Free skips sustain for fixed-duration articulation.
- Envelope Loop Off is one pass; AD-R repeats attack/decay while held, ADR-R adds release to that loop, and ADS-R adds another attack/release on key release. Free with AD-R/ADR-R behaves as permanently held: check note release before adopting the combination.
- **LFOs:** independently enable LFO 1/2; Rate is Hz or beats. Waves: sine, triangle, rectangle, stepped noise, smooth noise. Width shapes triangle into up/down saw or rectangle into pulses; 50% is symmetric, and Width is unavailable for sine/noise. Delay postpones onset, Attack fades intensity in, Retrig restarts at Offset.
- **Performance:** Volume is overall level. Vib is an extra pitch LFO for both oscillators; set amount/Rate, Delay/Attack, Error randomness, and Amt < MW relative to base amount. Uni stacks 2 or 4 voices with Detune and per-stack Delay. Gli provides Time and optional Legato-only slides; Const is fixed time, Prop takes longer for larger intervals.
- Keyboard Octave/Semi/Detune (global ±50 cents), PB Range, Stretch (positive sharpens upper/flattens lower pitches; negative reverses), and Error define tuning. Voices sets polyphony; Priority High sacrifices low notes, Low sacrifices high, Last sacrifices oldest. In Global's MPE view, Pressure and Slide each have two destinations/amounts and activity LEDs; Note PB is the per-note bend range. Diagnose silence by checking the whole oscillator→filter→amp path, not just an oscillator switch.

## Collision
- **Start with excitation and resonance:** enable at least one of Mallet/Noise **and** at least one Resonator; either missing group causes silence. For a struck bar/body relationship choose Structure 1 > 2; Resonator 1 also has its own stereo output and feeds Resonator 2 via a mono signal. For independent layers use 1 + 2, which sends the mixed exciters to both. Lower output before experimenting; resonance interactions can produce large jumps. Disable unused sections to save CPU.
- **Mallet:** Volume sets excitation strength, Stiffness trades a soft/long/dark impact for a short/bright one, Noise adds impact noise, Color filters that noise and has no effect when Noise=0. MIDI-tab Key/Vel modulate Volume, Stiffness, and Noise.
- **Noise:** white noise through LP/HP/BP/LP+HP plus ADSR; choose Freq, Res (bandwidth in LP+HP), Env Amt, and Volume. Key/Vel can affect frequency and volume. Long noise envelopes support sustained excitation rather than only struck sounds.
- **Resonator selection:** Beam for bars; Marimba for arch-cut bar overtone tuning; String for strings; Membrane for a rectangular drum surface; Plate for flat plates; Pipe for one adjustable opening; Tube for a tube closed at both ends. Quality Eco→High increases calculated overtones and CPU; Pipe/Tube omit Quality. Copy 1→2 / 2→1 transfers complete resonator settings.
- X-Y horizontal changes Decay, vertical Material/Radius. Material low lets low frequencies outlast high ones; high does the reverse. Pipe/Tube Radius instead lengthens decay/high-frequency sustain and can alter the fundamental at extremes. Key/Vel modulate Decay and Material/Radius. Membrane/Plate Ratio sets aspect ratio.
- Brightness raises upper partial amplitude; Inharm negative compresses partials, positive stretches them, with velocity modulation available. Hit moves excitation from center (0%) toward edge, Rnd varies it; Pos. L/R move pickup points similarly. These controls are absent for Pipe/Tube. Pipe alone has Opening: 0% closes its adjustable end, 100% opens both; velocity can modulate it.
- Note Off 0% leaves natural Decay untouched; 100% immediately mutes resonance. Tune is semitones, Fine ±50 cents; Key 100% follows notes, 200% doubles intervals, negative inverts tracking. Pitch Env/Time creates a pitch ramp, with velocity affecting its starting amount. Gain/Pan balance resonators; Pan has key modulation. Bleed restores some unresonated exciter, useful when low tuning/quality dulls it.
- **Motion/performance:** each LFO has sine/square/triangle/up/down saw/stepped or smooth noise, Hz/beat Rate, Amount, Offset and Retrigger, and two destinations scaled by overall Amount. LFOs can modulate one another; Key changes rate and velocity changes amount. MIDI/MPE pitch bend, wheel, pressure, and slide each route to two destinations with independent amounts; other Key/Vel controls are in MIDI/MPE. Voices limits polyphony; Retrig. reuses an already-playing note's voice. For unintended long tails check Note Off and retrigger before reducing all resonator decay.

## Drift
- **Sources:** Osc 1 offers Sine, Triangle, Shark Tooth, Saturated, Saw, Pulse, Rectangle; Shape changes each differently, visible in the combined waveform display. Shape Mod supports Env 1, Env 2/Cyc, LFO, Key, Velocity, Modwheel, Pressure, Slide with ±100% depth and can act even at Shape=0. Osc 1 Oct is octave tuning. Osc 2 offers Sine, Triangle, Saturated, Saw, Rectangle with Oct and semitone Detune.
- Two Pitch Mod slots use those same sources and ±100% amounts for both oscillators; an LFO in Ratio mode can produce FM. Enable oscillator/noise sources in the mixer; arrows independently send each through or around the filters. R resets both oscillator phases on a note; off is free-running. With filters enabled, increasing gain above the −6 dB default starts the first saturation stage; above 0 dB reaches the second.
- **Filter:** Type I is 12 dB/octave DFM-1 with internal distortion feedback; Type II is 24 dB/octave MS2 with soft-limited resonance. Freq/Res control low-pass, HP the high-pass. Key 0 ignores note pitch and 1 tracks low/high notes. Two Freq Mod slots give ±100% modulation. Click the filter area for its display: left dot horizontal adjusts HP; right dot horizontal adjusts LP, vertical adjusts resonance.
- Env 1 ADSR shapes total amplitude. Env 2 is a modulation source, not preassigned to amplitude; switch it to Cycling for repeated modulation retriggered per note. Tilt moves the envelope midpoint/slopes and Hold sets peak dwell. Cycling and LFO each offer Rate (Hz), Ratio, Time (ms), or Sync (beats).
- LFO waves: Sine, Triangle, Saw Up/Down, Square, Sample & Hold, Wander (smoothed random transitions), Linear Envelope, Exponential Envelope (the last two are one-shot decays). R controls restart/free-run; Amount sets intensity and its source/amount pair further modulates it.
- **Mod section:** three source/destination/amount slots, ±100%, using the source set above. Destinations: Osc 1 Gain/Shape, Osc 2 Gain/Detune, Noise Gain, LP Frequency/Resonance, HP Frequency, LFO Rate, Cyc Env Rate, Main Volume. If modulation is absent, inspect the chosen source's activation and the overall depth.
- **Voicing:** Poly uses 1 voice/note, Stereo 2 with Stereo Spread, Unison 4 with Unison Strength. Thus Voices 32 allows 32/16/8 simultaneous notes respectively. Mono plays one note using up to four component voices; Thickness 0 leaves one audible, increasing it adds the other three. Mono Legato preserves envelopes on overlap; Glide sets the overlapping-note slide time.
- Drift increases per-voice oscillator/filter randomness, not just a global detune. Set Volume and Vel > Vol separately; Transpose is ±48 st. Note PB disables/enables per-note bending independently of global PB Range. For inconsistent repeated attacks compare oscillator R, LFO R, and Drift before editing the MIDI.

## Drum Sampler
- Load a file by browser double-click or drag to the waveform. Sample Start/Length are percentages of the **whole file**; Shift-drag Start gives fine adjustment and zoom. Sample Gain spans −70 to +24 dB. Transpose spans ±48 st and Detune ±50 cents. Check the waveform region after changing any of these.
- **AHD articulation:** Attack reaches peak. Trigger continues through Hold after release; Hold=inf lets playback reach the sample end; finite Hold is followed by Decay to zero. Gate disables Hold and starts Decay on note release. Choose Gate for note-length control, Trigger for a one-shot independent of key duration.
- Hover the waveform for similar-sample Previous/Next and sample Hot-Swap. Show Similar Files opens candidates; Return to Reference restores the initial reference and Save as Similarity Reference changes it. Sample Hot-Swap replaces the file; title-bar Hot-Swap replaces the instrument. Compare the new sample at existing settings before changing the reference.

| Playback effect | Set these two controls | Use / interaction |
| --- | --- | --- |
| Stretch | Factor, Grain Size (ms) | Time-stretch without direct pitch change; granular artifacts are expected. |
| Loop | Loop Offset from Sample Start, Loop Length (ms) | Repeat a short region. |
| Pitch Env | Amount ±100%, Decay | Bend upward/downward then return to global base pitch. |
| Punch | Amount, Release | Fixed-attack ducking emphasizes the transient; Release restores gain. |
| 8-Bit | Sample Rate, Decay Time | Bit/sample-rate reduction plus a decaying low-pass. |
| FM | Amount, FM Frequency | Sine-wave pitch modulation. |
| Ring Mod | Amount, Ring Mod Frequency | Low rates give tremolo, high rates give ring-modulation components. |
| Sub Osc | Amount, Frequency 30–120 Hz | Add a sub using the device's attack/decay. |
| Noise / Noise Osc | Amount, Color | Add filtered noise using the device's attack/decay. |

- Enable Playback Effect On and choose one effect; X/Y vertical controls its first parameter, horizontal its second. Global pitch and played note affect time/frequency controls in Stretch, Loop, FM, Ring Mod, Sub Osc, and Noise Osc; FM/Ring Mod decay also follows global Decay. Recheck effects after transposition rather than assuming fixed timing.
- Filter choices are LP12, LP24, HP24 (Frequency/Resonance) and Peak (Frequency/Gain). Global Volume is −36 to +36 dB, with Pan and Velocity to Volume. Choose Velocity or Slide (MPE) as a modulation source and target Filter, Attack, Hold, Decay, FX1, or FX2; set Amount.
- Context options: Enable Per-Note Pitch Bend is on by default; Envelope Follows Pitch keeps the envelope aligned to the same sample portion when transposed. Drum Sampler > Simpler retains sample start/length, not a guarantee of identical synthesis. A Drum Rack pad's Save as Default Pad makes future empty pads load this configuration; use only if that persistent default is requested.

## Electric
- Build the tone through Hammer → Fork → Pickup, with Damper controlling key-release mechanics; click a section/icon to reveal controls. This is modeled, not a sample player. Hammer Stiffness sets hardness/brightness and has Vel/Key response. Noise sets impact level with Pitch/Decay and key-dependent volume. Force Amount sets impact strength, also modulatable by Vel/Key.
- Fork Tine Color balances low/high partials; Tine/Tone Decay govern held-note decay and Key can change tine level. Tone is secondary resonance. Release applies to both tine and tone after key-up.
- Pickup Symmetry 50% places it in front of the tine; lower/higher moves it below/above. Smaller Distance increases overdrive. Type R models electro-dynamic pickup, W electro-static. Input changes drive into the pickup; Output changes its output level (with Key modulation). For cleaner sound use lower Input and compensate with Output, rather than treating them as interchangeable gains.
- Damper Tone changes stiffness/brightness, Level its noise. Att/Rel −100 gives attack noise only, +100 release only, center both. Verify key-up as well as key-down when unwanted clicks or tails occur.
- Global Volume/Voices manage level/CPU; Semi and Detune (±50 cents) tune. Stretch positive sharpens high/flattens low notes, negative reverses, zero is equal-tempered. Pitch Bend and Note PB set separate global and MPE per-note ranges.

## External Instrument
1. For hardware choose the physical port in MIDI To, then its channel; for a multitimbral plug-in choose its hosting track, then the plug-in channel. Confirm the intended destination before sending notes or CCs.
2. Set Audio From to the connected hardware interface inputs (enabled in Audio Settings), or to the plug-in's auxiliary outputs. Its main output remains on the hosting track. Set return Gain conservatively and verify a known note reaches the intended return without clipping.
3. Correct only the extra external delay with Hardware Latency. Use samples for a digital connection to preserve sample count across sample-rate changes; milliseconds for analog to preserve elapsed time. Sample units permit finer analog adjustment, but switch back to milliseconds before changing sample rate.
4. If Hardware Latency is disabled, check Options > Delay Compensation. Internal routing disables this control because Live already compensates internal devices. For silence inspect MIDI port/channel, hardware state, enabled interface input, and selected return separately; a MIDI activity indicator alone does not prove an audio path.

## Impulse
- Drag files/clips into eight slots or use slot Hot-Swap. Slots are mapped across C3–C4; the folded MIDI editor shows their labels even without notes. Use Pitch to transpose or Scale to remap. Select a slot for its settings; hover for preview/solo/mute/Hot-Swap. Slot 8 Link makes slots 7 and 8 choke each other, suitable for an open/closed pair.
- **Edits latch at Note On**, including automation and clip envelopes. Retrigger to evaluate an edit; choose Simpler instead when continuous mid-note parameter changes are required. Start skips at most 100 ms; Transp is ±48 st with velocity/random modulation. Stretch −100…100% shortens/lengthens; Mode A suits low-frequency material, B high-frequency material; velocity can modulate stretch.
- Filter Frequency/Resonance shape each sample; frequency accepts velocity/random modulation. Saturator Drive also increases level: compensate slot Volume. Decay reaches 10 s; Trigger begins decay with the note, Gate waits for Note Off. Pan accepts velocity/random modulation, Volume velocity only.
- Global Volume, Transp, and Time affect the whole kit; Time scales stretching and decay. Individual slots can be routed to separate receiving audio tracks as well as using the mixed output; inspect the receiving track's available Impulse inputs rather than assuming a dedicated audio output tool. Verify whether slot/global settings or downstream processing caused a mismatch.

## Meld
- Enable engine A/B independently; disabling an engine also disables its filter, but disabling its filter leaves the engine active. Each has pitch (Octaves, Semitones, Cents), two oscillator macros, amplitude/modulation envelopes, LFOs, filter, matrix, and mix. Use Current Scale turns semitone transposition into scale degrees, including Pitch Quant modulation. Expand the device to see the full matrix; A/B selects the engine and Copy to A/B transfers modulation values. Check the selected engine before edits.

- **Envelopes:** ADSR with Attack/Decay/Release slopes; modulation envelope also has Initial/Peak/Final. Edit numbers, breakpoints, or slope diamonds. Trigger traverses all segments ignoring sustain hold; Loop repeats the full envelope; AD Loop repeats attack/decay. Link Envelopes couples the engines' amplitude/modulation envelopes for unified articulation; verify which paired controls move in the installed version.
- **LFOs per engine:** rates in Hz/beats with Phase Offset and Retrigger. LFO 1 types Basic Shapes, Ramp, Wander, Alternate, Euclid, Pulsate each have two shaping macros. Its FX1→FX2 chain applies two choices from 18 modulation-effect types in series; use the visible choosers/Info View for effect-specific behavior. Raw LFO 1 and processed LFO1 FX are independent matrix sources. LFO 2 has Sine, Tri, Saw Up/Down, Rectangle, Random S&H.
- **Matrix:** source columns and target rows; click a parameter to add a temporary row, then drag a cell to assign depth (the row persists if modulated). Some targets add modulation, others multiply; for time/rate scaling negative speeds up, positive slows. MIDI Velocity/Pitch last for the note; Random is sampled on each trigger. MIDI bend/Press/wheel and MPE Note Pitch Bend/Slide/Press can be driven from controllers or clip expression/envelopes.
- **Engine Settings:** Osc Key Tracking off fixes C3, or the scale root in that octave when scale mode is active. Phase Reset makes starts repeatable; it enables Phase Spread, which uses the matrix Spread source; with Phase Spread off start phase is zero. Oscillator Scale Awareness applies to marked Dual Basic Shapes, the four Swarms, and Chip. Filter Scale Awareness applies to Plate/Membrane Resonator. Check both per-engine awareness and global Use Current Scale.
- Portamento slides continuously, Glissando steps (scale degrees with awareness); both require overlapping notes and Glide Time >0, and operate in mono or poly. Separate Mono Legato governs envelope reuse, not the slide style.

| SVF 12dB / 24dB | L-B-H-N morphs low/band/high-pass/notch. |
| MS2 low/high-pass; OSR band-pass | Soft-limited Sallen-Key / hard-limited state-variable behavior. |
| LP Crunch 12dB; Filther | Distortion fed back into filtering / hard input clipping and soft output saturation. |
| LP Switched Res | Lofi higher gives stronger switching/downsampling artifacts; lower is smoother. |
| Eq Peak / Eq Notch | Boost / Cut around selected frequency, with width control. |
| Phaser | Six-stage inverted-feedback phasing; Feedback and Spread change intensity/notch spacing. |
| Redux | Crush controls bit depth; Lofi blends filtered rate reduction with unfiltered artifacts. |
| Vowel | Morph moves through vowel-like formants. |
| Comb + / Comb − | Feedforward/feedback combing; Feedback sets returned amount, Damp reduces high end. |
| Plate Resonator / Membrane Resonator | First 32 modes of a rectangular plate / circular membrane; adjust size, resonance and ratio / damping, optionally scale-aware. |

- Common filter controls are Frequency, Q and Drive (saturation before filtering). Mix Volume/Pan are per engine; Tone positive cuts lows, negative cuts highs. Global Drive follows the engine mix per voice, then Limit acts per voice; neither proves the final track cannot clip.
- Poly offers 2–12 voices; Mono can reuse envelopes with Legato. Stacked Voices duplicates both engines plus their processing per note, increasing CPU. Spread is only audible when assigned in the matrix: it offsets stacked voices, or distributes values among chord notes when stacking is Off. If Spread seems ineffective, inspect the assignment before increasing it. Global Volume sets output.

## Operator
- **Choose an algorithm before envelopes:** four oscillators can be carriers, modulators, or both; eleven diagrams route top→bottom. Select in Global, then adjust modulator Level and oscillator frequency ratios to change FM timbre; carrier level changes output. The algorithm itself can be mapped/automated/modulated. Select shell sections for detailed displays or fold the device when only shell controls are needed.
- Waves include sine, Sine 4 Bit/8 Bit, Saw D/Square D, harmonic-limited square/triangle/saw, Noise Looped, and random Noise White. Numbered wave names indicate harmonic count; lower counts reduce high-note aliasing. User allows additive drawing of 16/32/64 partials; Shift-drag isolates one harmonic. Repeat extends the pattern with a fade (low values brighter, high darker), Off truncates above the selected count. Context options restrict even/odd/all harmonics and Normalize; disabling Normalize can make added partials very loud.
- Osc Preview supports waveform copy/paste. Waveforms can be exported locally as .ams to User Library Samples/Waveforms and reloaded into an oscillator, Simpler, or Sampler. Oscillator shell/envelope context menus also copy settings; envelope menus set all levels to min/mid/max.
- Coarse sets integral ratios, Fine fractional ratios; Fixed substitutes Freq × Multi in Hz, down to 0.1 Hz, independent of played pitch. Osc < Vel changes frequency with velocity; Q quantizes it like Coarse. Level's Vel/Key controls shape dynamics (Key pivots at C3). Phase/R make starts repeatable; off is free-running. Feedback works only on an oscillator not already modulated by another and also depends on level/envelope.
- **LFO:** Low covers 50-second cycles to 30 Hz; Hi 8 Hz–12 kHz; Sync follows tempo. Rate < Key 100% doubles frequency per octave. Use classic waves, stepped S&H, or band-pass-filtered Noise. Dest. A buttons select oscillator pitches/filter cutoff with Amount A; Dest. B adds another target. Overall Amount, Amt < Vel, and the LFO envelope scale both routes; R selects retrigger/free-run.
- **Seven envelopes:** one per oscillator plus filter, pitch, LFO. Edit Initial/Peak/Sustain and Attack/Decay/Release; oscillator release ends at −inf dB (linear attack, exponential decay/release). Filter/pitch have adjustable slopes and End; LFO also exposes an end level. Release starts from the current level even if attack/decay is incomplete. Envelopes can be copied between oscillators.
- Loop repeats after decay/sustain using Loop Time; Beat repeats at the chosen beat interval without aligning an off-grid start; Sync aligns the first repeat to the nearest 16th while transport runs, otherwise behaves as Beat. Trigger ignores Note Off. Repeated envelopes move from their current level toward Peak to avoid restart clicks; verify rapid loops rather than assuming a discontinuous reset.
- Global Time scales envelope segments; Time < Key accelerates higher notes at positive settings; each Time < Vel scales its envelope. These do **not** change Beat/Sync repetition intervals. Pitch Env ±100% follows/inverts envelope levels; its destination buttons select A–D/LFO, plus Dest. B and its amount. A looping pitch envelope targeting only LFO rate and a looping LFO envelope can supply extra nested movement.
- **Filter:** use the shared filter choices above. Freq < Vel, Freq < Key (100% doubles/octave around C3), Envelope, and LFO modulate cutoff. Play by Key sets cutoff 466 Hz and key tracking 100%. Envelope 100% permits roughly nine octaves of cutoff movement. Res controls band-pass/notch width; Filter view and Envelope view share the display. Shaper selects a curve; Shp. Drive sets input and Dry/Wet blends it; 0% bypasses both shaper and shaper drive.
- **MIDI routes:** Velocity, Key, Aftertouch, Pitch Bend, Mod Wheel each offer two destinations; Time < Key and bend range have fixed first assignments. Targets include OSC Volume A–D, crossfades A/C and B/D, OSC Feedback, OSC Fixed Frequency, FM Drive (all modulators' levels), Filter Frequency, Filter Q (Legacy) versus Filter Res (updated), Morph, Drive, Filter Envelope Amount, Shaper Drive, LFO Rate/Amount, Pitch Envelope Amount, Volume, Panorama, Tone, Time, or Off. Morph only works on Morph; Filter Drive is unavailable there.
- **Performance/CPU:** up to 32 Voices; excess steals oldest. Voices 1 makes overlapping notes legato; global R retriggers repeated pitches instead of layering voices. Pan has key/random offsets. Glide slides from last pitch with Glide Time; legato glide avoids envelope restart. Spread uses two detuned panned voices, its enabled state decided at Note On. Transpose also affects already-playing notes. PB Range handles global bend; Enable Per-Note Pitch Bend is on by default in the title context menu.
- If high notes become inharmonic, compare simpler waves, lower Tone, and Antialias (on for new patches) before changing the composition. To reduce CPU, reduce voices/Spread and disable unused filter, LFO, or pitch envelope; Interpolation/Antialias off trades quality for CPU. Turning off oscillators does **not** save CPU. Use Info View for the selected control when legacy/current filter labels differ.

## Sampler
- **Choose multisampling for range-dependent timbre**, or use one file with its deeper modulation. Load a preset, arm/monitor the track, and verify input. Zone controls mapping; Sample controls the selected layer; Pitch/Osc, Filter/Global, Modulation, MIDI expose synthesis/performance; tab LEDs indicate modulation. Title options include Group into an Instrument Rack, Fold/unfold, Show Preset Name, control-surface locking (hand icon; arming auto-locks by default), and saving a requested default. Conversion to Simpler is available, but verify behavior rather than treating it as a lossless interchange.
- **Map layers:** import files into the layer list, name them by role/root, and select a layer to edit it in Sample. Auto selects all layers eligible for each incoming note. Newly imported key zones span the full keyboard; drag edges for bounds, bodies for position, upper corners for fades. Key uses note range, Vel uses 1–127, Sel uses 0–127 independent of MIDI type. A layer must pass its applicable zones. Lin/Pow switches all zone fades between linear and constant-power; this is separate from loop crossfades.
- Sample Selector changes eligibility for **future triggers**, not the file already sounding. Use Select All With Same Range in the active zone editor, sort by name/key/velocity/selector, and Small/Medium/Large zoom to inspect mappings. Distribute Ranges Equally covers C−2–G8; Around Root Key creates nonoverlapping ranges around different roots (shared roots distribute evenly). Show in Browser / Manage Sample locate assets. Normalize Volume uses sample peak headroom; Normalize Pan balances stereo energy, not necessarily a centered pan setting.
- **Round robin:** enable RR for layers sharing the key zone; Forward follows list order, Backward reverses, Other avoids consecutive repeats, Random permits them. Reset Interval restarts predictably: Forward at top, Backward at bottom, Other/Random at the first-played sample. Test repeated notes across a reset boundary and different velocities; do not confuse sample selection with continuous sample morphing.
- **Selected-layer playback:** RootKey defines untransposed pitch; Detune ±50 cents, Volume up to +24 dB, Pan are layer-specific. Reverse is instead global/modulatable and plays backwards without creating a new file. Sample Start/End limit playback independently of envelope duration; a slow amplitude attack can delay the audible onset. Time boxes can display samples or minutes:seconds:milliseconds. Ctrl-scroll (Windows) / Cmd-scroll (Mac) zooms.
- Snap moves boundaries to left-channel zero crossings; a stereo click may still need Crossfade. A brace context-menu Snap Marker handles individual regions. Link ties Sample Start to Loop Start while retaining the previous Start for recall when unlinked. Without sustain looping, playback ends at Sample End or completion of amplitude release, whichever occurs first.
- Sustain forward loops Loop Start→Loop End; back-and-forth reverses at boundaries. With Release Mode off it keeps using that sustain loop through the amplitude release. With release enabled it proceeds toward Sample End; Release Loop loops from its own start to Sample End, forward or back-and-forth, until amplitude release finishes. Release modes require sustain looping. Separate loop Detune compensates pitch changes from very short loops; Crossfade reduces transition clicks. Default loop fades are constant-power; the title option switches them to linear.
- Interpol Normal/Good/Best trades transposition quality for CPU. RAM loads the entire multisample and can improve start/end modulation but risks memory pressure. Waveform vertical zoom and B/M/L/R (Both/Mono/Left/Right) only affect display, not audio routing.
- **Envelope controls:** ADSR plus applicable Initial/Peak/End and slopes; positive slopes front-load movement. Loop/Beat/Sync provide repeated envelopes and Time/Repeat sets return/repetition timing; Trigger ignores Note Off. Exact Trigger/restart behavior should be checked in the installed version with short and held notes before relying on it. Time < Vel changes segments, not Beat/Sync beat intervals. Filter/Global's amplitude envelope shapes all layers; global Time and Time < Key scale envelope durations.
- **Pitch/Osc:** the per-voice oscillator modulates the sample and is never heard directly. Choose FM for pitch modulation or AM for amplitude modulation; 21 wave types and its own loopable envelope are available. Volume is depth, Vol < Vel its velocity response. Fixed uses Freq × Multi independent of notes; otherwise Coarse 0.125–48 and Fine 0–1000 set tracking ratios. Pitch envelope Amount is in semitones and also bends the modulation oscillator when enabled.
- Global Spread adds two detuned voices/note and doubles processing. Transp/Detune tune all samples; Zn Shft changes which key zone supplies the sample while retaining played pitch. Glide is monophonic; Portamento polyphonic; Time controls the transition.
- **Filter/Global:** use shared circuit/filter choices. Enable F. Env and nonzero Amount for cutoff-envelope action. Shaper offers Soft/Hard/Sine/4bit and Amount; routing arrow up means shaper→filter, down filter→shaper. Pan and Pan < Rnd apply globally. Voices reaches 32; R reuses an already-playing pitch and helps avoid piling up long releases.
- **Modulation:** Aux is a loopable envelope with two independently scaled destinations from 29 choices. Three LFOs offer sine/square/triangle/up/down saw/S&H, 0.01–30 Hz or 1/64-note–8-bar sync, Attack, Retrig, Offset, and Key-to-rate. LFO 1 directly reaches Vol/Pan/Pitch (0–100) and Filter (0–24). LFOs 2/3 each have two destinations and stereo Phase (equal rate, shifted phase) or Spin (right channel up to 50% faster). They can modulate one another.
- **MIDI/imports:** Key, Velocity, Release Velocity, Aftertouch, Modulation Wheel, Foot Controller, Pitch Bend each route twice with Amount A/B; bend range is 0–24 semitones from 14-bit wheel data. Supported imports here are REX (Standard/Suite only), ACID Loops, Soundtrack Loops; ACID/Soundtrack tags are not accessible. Drag from the browser into the Set; imported presets appear in User Library/Sampler/Imports, sometimes as Racks with multiple Samplers. Do not infer support for other library formats.

## Simpler
- Load a file or drag an audio clip: clip region/loop bounds and warp settings transfer. Sample contains waveform/playback; Controls contains synthesis; expand via the title button for a larger sample view. Waveform Hot-Swap changes only the sample; Ctrl-scroll (Windows) / Cmd-scroll (Mac), or vertical drag, zooms and horizontal drag pans.

| Playback mode | Configure | Verify |
| --- | --- | --- |
| Classic | Polyphonic pitched instrument; ADSR, Loop, Voices, Retrig. Flags set absolute available region; Start/Length are percentages **within it**, Loop sets the looping portion. | Sustained/released notes; enough Voices; release tails and same-pitch repeats. |
| One-Shot | Strictly monophonic, no loop/Length/Voices. Trigger plays through regardless of key-up; Gate starts Fade Out on release. | Trigger's Fade Out begins that duration before region end; Gate's starts at key-up. |
| Slicing | Slice By Transient (Sensitivity, up to 64), Beat (Division), Region (equal Regions), or Manual (double-click). | Notes address slices chromatically; test boundaries and selected playback behavior. |

- In Classic, Snap uses left-channel zero crossings and Fade crossfades loop boundaries; stereo clicks can survive Snap. Fade is unavailable when Warp is on. Gain is the sample input level; Volume is final post-filter output. Voices steals oldest when exceeded. Retrig cuts a sustaining same-pitch note instead of overlapping it; it is audible with long release and more than one voice.
- Slicing Playback Mono chokes previous slices; Poly exposes Voices/Retrig; Thru plays monophonically from the selected slice through the remaining region. Trigger/Gate work as in One-Shot. Fade times apply per slice in Mono/Poly, but from selected slice to region end in Thru. Automatic markers are blue, manual white; drag to move, double-click to add/remove, Alt/Option-click in Transients toggles automatic/manual. Manual transient slices survive Sensitivity changes.
- **Warp:** off couples pitch and speed; on retains Set tempo across notes. Dragging a previously warped clip retains its warp edits. Choose the available Warp Mode for the material, then Warp as… for a precise bar/beat length; if detection is doubled/halved, ÷2 doubles playback speed and ×2 halves it. Verify against the transport rather than trusting the detected length. Tiny loops with Complex/Complex Pro may be very CPU-heavy.
- **Synthesis:** use the shared filter choices; cutoff receives velocity, key, envelope, LFO. Classic amplitude plus filter/pitch ADSR shape articulation; filter/pitch need their amount controls. For the amplitude envelope, Loop/Trigger use Time for the Sustain-to-Initial return, with held notes able to restart after Decay; Beat/Sync use Rate for repeats. Verify Trigger with held/released notes rather than confusing it with One-Shot Trigger. The LFO is per voice: sine/square/triangle/up/down saw/random, 0.01–30 Hz or beats, Attack, R, Offset (only effective with R), Key-to-rate, and Volume/Pitch/Pan/Filter depths.
- Global Pan plus Random > Pan/LFO controls stereo placement. Spread adds two detuned panned voices, enabled per note at Note On. Volume and Velocity > Volume govern output dynamics. C3 plays original pitch; Transpose ±48 st, Detune ±50 cents, MIDI pitch bend ±5 st. Glide is mono, Portamento polyphonic, Time sets transition duration.
- **Context workflows:** Use Constant Power Fade for Loops can be disabled for linear fades. Simpler → Sampler enables a multisample workflow but loses Simpler warp/slice behavior; preserve a comparison before conversion. Manage Sample/Show in Browser locate files; Show in Finder/Explorer is unavailable for official Pack samples. Normalize Volumes uses peak headroom. Crop and Reverse create processed copies, preserving the original audio file.
- Slice to Drum Rack replaces the current Simpler with pads; Slice to New MIDI Track retains it and creates another track, a Rack, and an ordered playback clip. Choose the latter when preserving the source instrument is required; verify timing and pad mapping. To reduce CPU, reduce voices/Spread, avoid unnecessary Complex modes, disable unused filter/LFO, and prefer 12 dB over 24 dB only if the changed filter response is acceptable; stereo samples cost more than mono.

## Tension
- **Model the interaction:** String is excited by Bow, Hammer, Hammer (bouncing), or Plectrum; Termination changes effective length, Damper mutes/excites, Pickup captures it, filter precedes Body. String tab contains physical components/Vibrato; Filter/Global contains filter modulation, MPE and performance. Disable unused sections to save CPU (String/Keyboard cannot be disabled). If both Exciter and Damper are off there is no excitation; even enabled components can cancel through extreme combinations. Keep level low and change one physical parameter at a time.
- **Exciter selection:** Bow sustains through friction (Force increases scratchiness, Friction usually quickens attack; no Damping). Hammer strikes once from below; bouncing hammer drops from above and can strike repeatedly; both have Mass/Stiffness. Plectrum uses Protrusion (how much pick catches the string) and Stiffness.
- Shared Velocity sets exciter speed, Position contact point (0% termination, 50% midpoint), and Damping impact absorption. For bouncing hammer, more Damping shortens interaction and often brightens/loudens it. Fix. Pos keeps the physical location fixed as pitch changes (guitar-like); off makes it proportional to string length (piano-like). Vel/Key sliders vary responses with performance.
- **Damper:** Mass presses harder/mutes faster; Stiffness changes material; extreme mass/stiffness can change tuning. With Gated on it contacts the string at key release; Velocity controls application/removal speed and can produce a very loud release. Gated off leaves it on the string and disables Velocity's effect. Position/Fix. Pos and Key modulation set contact behavior. Damping above roughly 50% can bounce the damper and **lengthen**, not shorten, decay.
- **String:** Decay controls resonance length, with < Key scaling. Ratio 0% uses the same decay for onset/release; increasing it shortens release only. Inharm detunes upper partials. Damping here is counterintuitive: increasing it retains **more** high-frequency content (less damping), with key scaling. Distinguish it from damper Damping.
- **Vibrato:** Rate/Amount, Delay/Attack, < Mod relative to base Amount, and Error randomizing those properties. **Termination:** Finger Mass/Vel/Key, Finger Stiff, Fret Stiff model finger/fret contact. **Pickup:** Position 0% termination→50% midpoint, generally thin/bright→full. **Body:** choose type and Size XS–XL; larger lowers resonances. Decay sets ring, Str/Body blends direct string with body (left bypasses body, right body-only), Low Cut/High Cut refine it.
- **Filter:** 2nd/4th-order low/high/band-pass, notch, formant; formant Res selects vowels. Freq/Res accept Key, envelope, LFO modulation; envelope/LFO must be independently on. ADSR attack Vel shortens at higher velocities; sustain Vel raises level. Filter LFO offers sine/triangle/rectangle/stepped or smooth random, Hz/beats Rate, Attack/Delay.
- **MPE:** Pressure and Slide each route to two destinations/amounts; activity LEDs confirm incoming data. Pitch Bend and Note PB set separate global/per-note ranges. **Keyboard:** Octave/Semi/Detune (±50 cents), Voices, Stretch (positive sharpens highs/flattens lows), Error random tuning, Priority High/Low/Last chooses which pitches/old notes survive voice pressure.
- **Portamento:** Time, optional Legato-only overlapping-note slides, Prop. for interval-dependent duration (off is constant). **Unison:** 2 or 4 voices with Detune/Delay. Volume is shared between both tabs. If a patch is silent, reduce over-damping or increase compatible excitation instead of merely raising output; if key-up bursts occur, inspect Damper Velocity first. Compare with a known working preset to isolate interacting parameters.

## Wavetable
- **Build movement:** enable Osc 1/2, choose category/table, then move Wave Position through the table to change timbre over time. Gain/Pan/Semi/Detune are per oscillator relative to global Transpose. Arrow navigation crosses categories. Raw unmodulated oscillators are band-limited; that does not guarantee arbitrary modulation/effects stay alias-free. Expand via the title button if controls are hidden by screen layout.
- Drag WAV/AIFF onto the table display to import; choosers/arrows then browse its folder. Normal import processing reduces artifacts; Raw bypasses processing for prepared tables or deliberately rough results. Linear bottom→top and polar inside→outside displays show the same table. Verify the imported table through its full position range, not only its initial frame.
- **Oscillator effects:** FM Amt sets depth; Tune ±50% is an octave up/down, ±100% two octaves, intermediate values inharmonic. Classic offers PW for any table and hidden-oscillator Sync. Modern offers Warp and Fold. The two parameter values persist when changing effect type, so recheck them after switching. Sub has Gain, Tone (0% sine, increasing harmonics), and octave-down switches for one/two octaves relative to note/global transpose.
- **Filters:** use the shared filter choices. Serial sends main sources through Filter 1→2; Parallel sends them to both; Split sends Osc 1→Filter 1 and Osc 2→Filter 2. Sub is sent to both filters, split in half in Split. An off filter in Split does not silence its oscillator; with mains disabled, both filters can separately process Sub. Drag filter dots to change Frequency/Resonance.
- **Matrix/MIDI:** click a parameter for a row and drag a source-target cell to set depth; unmodulated rows disappear on another selection, modulated rows persist. Matrix and MIDI share rows; source headers jump to their editor. Additive targets use base + sum(source contributions), neutral 0. Multiplicative targets use base × product(source factors), neutral 1, minimum 0: a zero base may defeat modulation. Amount globally scales matrix modulation and is multiplicative.
- Time negative accelerates all modulators, positive slows them; a modulator assigned to Time does not time-modulate itself. MIDI Velocity/Note persist for the note, Random redraws per trigger; Note is centered on C3 and 100% to Filter Frequency gives exact pitch tracking. Bend, aftertouch, wheel can also be driven via clip envelopes.
- **Envelopes:** Amp plus Env 2/3 have ADSR/slopes; only Env 2/3 expose Initial/Peak/Final. None holds sustain until release, Trigger runs all stages once, Loop repeatedly traverses them without sustain hold until the voice ends. Sustain and Initial are multiplicative destinations. Positive slopes move early, negative late. Check both note-on and note-off envelope results.
- **Two LFOs:** Sine/Saw Shape bends slope; Triangle Shape shifts ramp↔triangle↔saw; Square Shape changes pulse width; Random Shape changes extreme-value distribution. Rate uses Hz or beats; drag the waveform to adjust it. Amount is multiplicative, Attack fades in, Retrigger restarts at Offset; Offset itself cannot be modulated.
- **Voicing:** Mono uses legato envelopes and permits overlapping-note Glide; Poly exposes Poly Voices and disables Glide. Unison Classic detunes evenly/pans alternately; Shimmer slowly jitters pitch plus slight table offset; Noise jitters faster; Phase Sync restarts detuned oscillators together; Position spread distributes table positions with slight detuning; Random note randomizes position/detune per trigger. Unison Voices counts oscillators **per wavetable oscillator**, not notes. Amount varies effect strength; Unison Amount and global Volume are multiplicative targets.
- **Quality/CPU:** title context Hi-Quality off calculates modulation every 32 samples and uses lower-cost filters, potentially saving up to 25% CPU; this is not a measured guarantee for the current Set. New instances/Core Library presets default to off from Live 11.1 onward; older user presets/Sets retain high quality for consistency. Compare sound and CPU before changing an existing patch, since subtle differences are possible.
