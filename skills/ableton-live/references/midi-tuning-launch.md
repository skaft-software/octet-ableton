## Scope and preparation
- These are Live 12 **UI procedures**, not a claim that any automation interface exposes them. Discover available controls before acting; leave tool/API mapping to the integration's capability inventory.
- MIDI clips contain performance instructions, not audio. For audible checks, use an instrument on the MIDI track or a correctly routed external instrument. Do not confuse a note's velocity with a guaranteed loudness change: the receiving instrument determines the response.
- Establish the intended clip, track, time range, selected notes, scale/tuning, grid, and loop before edits. Many buttons affect the entire clip when nothing is selected. Preserve a duplicate before replacements, cropping, retuning, or generative experiments; use Undo for unintended note changes.
- Imported MIDI is incorporated into the Set; editing it does not rewrite the original MIDI file. This does not protect the edited clip inside the Set.
- In shortcuts below, **Primary** means Ctrl on Windows / Cmd on macOS. **Grid override** means Alt on Windows / Cmd on macOS; **Alt/Option** means Alt on Windows / Option on macOS. These modifiers are not interchangeable.

## Create, navigate, and select notes
1. Create a MIDI clip by recording or Capture MIDI, double-clicking an empty MIDI Session slot or Arrangement track area, or selecting an empty slot/Arrangement timespan and using Create → Insert Empty MIDI Clip(s) (Primary+Shift+M).
2. Double-click the clip and select **Notes**. Time runs horizontally; pitches, tuning degrees, or Drum Rack pads run vertically. Standard note labels span C-2–C8. Preview above the piano ruler auditions keys and added/moved notes when an instrument is present; its state is shared across MIDI tracks. Armed track + Preview also permits step recording.
3. Double-click the grid to add a note, or press B for Draw Mode and drag. In Draw Mode, clicking existing notes removes them; outside Draw Mode, double-click removes them. Check **Draw Mode with Pitch Lock** in Display & Input Settings: Alt/Option temporarily reverses this preference. Freehand drawing can cross pitches; pitch-locked drawing stays on one row and erases drawn notes when retracing toward the first note.
4. Drag vertically in the time ruler to zoom time, horizontally to pan; drag horizontally in the note ruler to resize pitches and scroll it to change register. In-editor scrolling with Primary changes time zoom; Alt/Option changes pitch zoom. Double-click either ruler to fit that axis to the selection, or all notes when nothing is selected. If the selection is offscreen, this brings it back.
5. Use the bottom-right clip overview to pan inside its outline, zoom by vertical dragging, or resize the outline's edges. Page Up/Down scrolls octaves; Shift reduces this to one pitch row. +/− zooms around the time selection, Z fits selection, X shows the clip, and Alt/Option + +/− adjusts editor zoom. Drag the Clip View divider for space, or View → Expand Clip View (Primary+Alt/Option+E).
6. Configure the grid in the header or toggle Snap to Grid (Primary+4). Grid override temporarily reverses snapping. A moved note first travels freely to the next grid/offset point, then snaps; an existing timing offset can be retained rather than quantized away.
7. Enable Follow in the Control Bar to scroll with playback. Editing pauses it; re-enable Follow or stop/restart playback to resume. Scrubbing uses global quantization: click the scrub area when **Permanent Scrub Areas** is enabled; otherwise Shift-click the scrub area/time ruler. **Chase MIDI Notes** lets sustained notes sound when playback starts after their note-on.

### Selection and filters
- A blank click places the insert marker; Left/Right moves it by the grid, Home/End to clip boundaries, and Ctrl (Win)/Option (Mac)+Left/Right to neighboring note boundaries. Paste starts at this marker.
- Drag a rectangle to select time and enclosed notes; Enter alternates between the time and note selection. Shift+arrows extends/narrows time; add grid override for unsnapped movement, or Alt/Option with Shift for note-boundary movement. Esc or a blank click clears selection. Arrow keys move/transpose selected notes instead of merely moving the insert marker.
- Click a note; Shift-click adds/removes it. Shift-click a piano key adds/removes that whole pitch row. Primary+A selects all; Invert Selection (Primary+Shift+A) swaps selected/unselected notes without changing pitches.
- Keyboard note selection: Ctrl (Win)/Option (Mac)+Up/Down chooses a note near the insert marker, then next/previous notes in time; Left/Right with the same modifier navigates within one pitch. Add Shift to Up/Down to accumulate notes.
- Enable **Find and Select Notes** in the header. Adjusting a filter immediately selects matches; a yellow dot marks applied filters. Combine filters for narrower searches; **Invert** reverses a filter and **Select** reapplies its saved criteria. Clicking the grid deactivates filters and deselects notes. Manual Shift selections remain available; Shift-drag can make equally spaced repeated time selections.

| Filter | Use and exact boundary |
| --- | --- |
| Pitch | Select pitch classes with Pitch toggles; applies across octaves. |
| Time | Set Start, Length, and Repeat in beats for recurring windows. |
| Chance | Select the Min/Max Probability range. |
| Condition | Active selects enabled notes; Chance selects values below 100%; Velocity Deviation selects notes with a deviation range. |
| Count | Every selects each nth note/chord; Offset changes the first counted item. Quantized counts grid-cell groups as one item, not individual notes. |
| Duration / Velocity | Use the respective minimum/maximum sliders to select a value or range. |
| Scale | Use Clip Scale follows the clip; disable it to choose an independent Scale Root and Scale Name. |

## Edit note geometry
- Move selected notes by dragging or arrow keys; grid override+Left/Right nudges without snapping. Ctrl (Win)/Option (Mac)+drag copies, even if added after dragging begins. Overlapping a same-pitch note's beginning can replace it; overlapping its end can shorten it. Inspect collisions after edits.
- Drag either note edge to resize; Shift+Left/Right changes length by the grid, with grid override for fine movement. **Fit to Time Range** (Primary+Alt/Option+J, or Duration chooser → Set Length) aligns note starts/ends to the selected time/note range; it is not proportional stretching.
- Select multiple notes or a time range to expose stretch markers beneath the scrub area. Drag either end for proportional timing/length changes; the temporary marker between them redistributes material inside the fixed boundaries. Crossing the end markers reverses order. Linked clip envelopes follow stretching; unlinked envelopes do not. Grid override bypasses snapping.
- Press 0 to deactivate/reactivate selected notes without removing them; gray notes do not play.
- **Split:** hold E and draw across notes, or drag horizontally inside a note to position a split; Primary adds grid snapping. With no notes selected, Primary+E / Split Note(s) divides notes crossing the insert marker or time-selection boundaries.
- **Chop:** with notes selected, Primary+E / Chop Note(s) on Grid divides them by the current grid. Continue holding Primary and press Up/Down to change the number of pieces; add Shift for powers of two. Mouse equivalent: E+Ctrl (Win) / E+Option (Mac), then vertical drag; Shift again changes by powers of two.
- **Join Notes** (Primary+J) combines selected same-pitch notes; their MPE envelopes are joined as well. Check the resulting span, not merely the number of notes.

| Pitch and Time Utilities control | Decision and behavior |
| --- | --- |
| Transpose | Drag/type a semitone offset, or scale-degree offset when clip Scale Mode is active. Up/Down moves notes; Shift+Up/Down moves octaves. |
| Fit to Scale | Requires an active clip scale; moves to the nearest allowed degree, choosing the lower degree on an exact tie. |
| Invert | Flips pitches between the highest/lowest notes; with a scale, uses scale degrees. This is not Invert Selection. |
| Interval Size / Add Interval | Adds shifted copies for chords. Changing Interval Size with notes selected immediately adds/selects new notes; without selection it only sets the amount until Add Interval applies it to all notes. |
| Stretch Factor / ×2 / /2 | Factor changes note timing/length without changing loop length. ×2 and /2 double/halve note durations, time selection, or loop region as applicable. |
| Duration / Set Length | Choose grid-based, explicit, or Fit to Time Range duration. With no note selection, Set Length affects every note. |
| Humanize Amount / Humanize | Randomizes starts by up to one quarter of a grid division before or after the original position. |
| Reverse | Reverses time order of selected notes, or the entire clip if nothing is selected. |
| Legato | Extends/shortens each note to the next note's start and the last note to loop end; Span offers additional articulation controls. |

## Velocity and probability
- Use the Lane Selector to show **Velocity**, **Chance**, or **Release Velocity**. The all-expression toggle shows/hides enabled lanes; Swap Lane in a lane header changes the visible editor. Drag lane dividers to resize, or use Alt/Option+wheel/pinch. Hover a note to identify its marker among stacked notes.
- Drag a velocity marker, type its value then Enter, or Alt (Win)/Cmd (Mac)+vertical-drag a selected note. Shift-select multiple markers; to equalize unequal velocities, drag them all to an extreme and then to the target. Primary+Up/Down changes selected velocity markers by 10; add Shift for fine adjustment. Note-color saturation reflects velocity.
- **Randomize** changes stored velocities once: Randomization Amount gives a symmetric maximum increase/decrease from existing values; entering an amount and pressing Enter triggers it. With no selection, Randomize affects all notes. **Ramp Start Value / Ramp End Value** distribute selected velocities evenly between endpoints.
- **Velocity Deviation** instead chooses a new velocity at every playback. Positive deviation ranges upward, negative downward: velocity 60 with +20 yields 60–80. Bounds depend on each note's headroom to 127, so mixed selections show ranges. Primary+drag from a velocity marker also sets deviation; double-click its marker resets deviation to zero. A shaded region/dot identifies deviation.
- In Draw Mode, drawing velocity affects notes in each grid cell, restricted to selected notes if any. Hover highlights affected notes. Disable grid/hold grid override for individual markers; Alt/Option+drag draws a straight ramp and Shift makes it horizontal. Select one piano row first to limit a ramp to one voice.
- **Release Velocity** edits note-off speed, not note-on velocity. Only supporting instruments respond; Sampler can use it as a modulation source.
- **Chance** ranges 0–100%. Drag/type markers; Up/Down adjusts by 10 percentage points, Shift gives finer adjustment. Notes below 100% show a small corner triangle when tall enough. Randomization Amount is relative to the current chance: 50% ±25% produces 25–75%. With selected notes, changing the amount immediately randomizes; without selection, Enter or Randomize applies to all notes.
- **Play All** groups notes under one shared chance decision; **Play One** randomly chooses just one group member according to the group probability. Select notes and use those buttons or Group Notes menu entries. Primary+G repeats the last group type, so use an explicit button when the type matters. Group markers use diamond handles for Play All and triangular handles for Play One.
- Hovering a member highlights its group; the Status Bar shows type (an asterisk indicates mixed groups). Grouped notes retain corner triangles even at 100%. Change type via the marker's context menu or buttons. Ungroup / Primary+Shift+G removes selected members; selecting all members dissolves the group. Moving a note into another group removes its old membership.

## Scales, clip structure, and multi-clip editing
- **Fold to Notes** (F) hides unused rows; its setting is shared across clips, but visible rows depend on each clip. With Drum Rack, Fold shows only rows containing notes; without Fold, rows with devices are shown. This is visibility, not pitch correction.
- Enable **Scale Mode**, then choose Root Note and Scale Name in Clip View or the Control Bar. Piano keys indicate allowed notes; **Highlight Scales** (K) also colors their rows and emphasizes the root globally. **Fold to Scale** (G) hides non-scale rows except those already containing notes. Use Fit to Scale separately if pitches must change.
- New clips inherit the foreground/most recently selected clip's scale configuration; when Scale Mode is disabled, inherited settings remain inactive. Piano-ruler spelling options choose flats, sharps, both, Auto, or MIDI numbers. With Scale Mode active, spelling preferences affect only out-of-scale notes; Auto follows the root's circle-of-fifths position.
- For a requested trim, inspect loop state first: **Crop Clip** retains Start–End when unlooped, or the earlier of clip start/loop start through loop end when looped. **Crop Clip to Time Selection** retains the selected range. These discard other MIDI data and create no disk file; verify pickup notes and retained boundaries on a copy. Do not crop merely to change the playback region.
- **Duplicate Time**, **Delete Time**, and **Insert Time** change the timeline contents, unlike ordinary note clipboard operations. Duplicate copies the selected interval; Delete closes the time gap; Insert places an equal empty interval before the selection. These do **not** change clip start/end or loop settings: inspect those separately.
- MIDI clips loop by default. Drag loop start/end to audition a region, including during playback. Select the loop brace and Primary+D to double it, duplicate its notes, and move notes to its right by the added length. Disable Clip Loop for one-shot playback; the brace becomes gray.
- Multi-select clips to compare/edit notes together. Colored loop bars identify clips; click a bar/note to set the foreground clip. The title shows its name, or track name if unnamed. Loop, time signature, groove, and scale controls can affect all selected clips; Velocity/Chance lanes **only affect the foreground clip**.
- **Focus Mode** (N; hold N for a temporary toggle) restricts editing to one clip, graying others; hovering another loop bar reveals its color/notes, and clicking selects it. Only one loop bar can be edited in Focus Mode. The active clip's scale controls Fold to Scale; Fold to Notes considers notes across the selection.
- Without Focus Mode, edit across clips and loop boundaries. Primary-click/drag loop markers for noncontiguous multi-selection; Shift selects adjacent bars; Primary+D duplicates selected bars. Resize loop-bar height above the title's scrub area. Mixed scale/root settings display an asterisk. Copy/paste returns notes to their original set of clips only while clip selection/foreground remains unchanged; selecting another clip makes it the paste target.
- **Session:** at most eight MIDI clips, all looped; bars sort by track then scene. Different loop lengths repeat visually until they realign; darker regions lie outside a clip's loop, and a start before loop start shifts displayed loop positions.
- **Arrangement:** clips from at most eight tracks across a timespan; bars sort by track and time. Drawing can cross clip boundaries unless Focus Mode is on. The editor fits first-clip start through last-clip end, excluding surrounding silence; mixed looped/unlooped selections show a half-colored Loop control.

## MIDI Tools: application rules
1. Use **Transform** for existing material and **Generate** for new material. Choose a tool, establish selection, then adjust parameters. A transformation targets selected notes, a time selection, or the clip loop when neither is selected. Generators target the time selection or loop; generated notes can replace overlapping existing notes, so protect populated targets first.
2. **Auto Apply** is on by default: parameter changes immediately change notes. Turn it off to restore original notes and set parameters without applying. Then use **Apply**, or Primary+Enter from the editor. Check the actual note result before continuing; random operations can produce a new result on each application.
3. Undo/Redo restores note edits, **not tool settings**. **Reset** restores the selected tool's parameters, **not notes**. Scale-aware pitch controls use scale degrees rather than semitones when a clip scale is active.
4. Native tools are fixed implementations. **Velocity Shaper** and **Euclidean** are bundled Max for Live tools in Standard and Suite. Editing/building tools or using third-party Max tools requires Suite or Standard with the Max for Live add-on. Confirm installed-version availability before relying on any tool.
5. Max MIDI Tools are `.amxd` files, distinct from track devices. Recognized locations are `MIDI Tools/Max Transformations` and `MIDI Tools/Max Generators` within the User Library, or folders already added to browser Places. Locate them through the MIDI Tools filter group / MIDI Tool content tag; do not install unapproved third-party code.

## Transformation catalog
- **Arpeggiate:** turn held notes/chords into a written arpeggio. Style offers 18 Arpeggiator-derived patterns; Distance controls transposition per step (degrees/semitones), Steps the number of transposed steps, Rate the spacing, and Gate the duration. Gate below/above 100% shortens/extends notes. Check order, note ends, and overlap after application.
- **Chop:** set Parts to 2–64; the editable Pattern is at most 16 parts and repeats above that. Positive Gaps inserts one gap after that many notes; negative Gaps inserts that many gaps after each note. Pattern toggles override individual gaps; a dash in Gaps marks customization, which is replaced if Gaps is moved again. Emphasis selects notes/gaps for **Stretch Chunk(s)** at 2–8× relative length; emphasized Pattern toggles gray out. Variation randomizes starts/ends. Inspect the full repeated pattern, not just its first 16 parts.
- **Connect:** fill between existing notes. Spread limits random pitch displacement from source pitches; Density is the percentage of the intervening time filled (100% fills all gaps). Rate sets connecting-note length; Tie is the probability of extension to the next original note. Placement is randomized, not a fixed interpolation guarantee.
- **Glissando:** select at least two notes and connect successive pitches with per-note pitch bend. Start is a percentage of note length; Curve shapes the glide. Drag the displayed breakpoint horizontally for Start, or curve vertically for shape. Inspect in the MPE editor, not Notes view; when folded, use the dedicated Pitch Bend expression lane if available.
- **LFO:** choose Pitch Bend, Slide, or Pressure as Target; choose Sine, Square, Triangle, or Random Shape Type and adjust Shape. Random offers Reseed. Envelope Attack/Decay share the envelope's duration: Attack 100% forces Decay to 0%. Rate spans 1–1/128 in musical time; 1 means four beats. Positive Time Shift delays the oscillator; negative shifts phase. Amount for Pitch Bend can span twice the clip bend range (±60 st range permits −120…120 st); Amplitude Base stays within that range (−60…60 st). Slide/Pressure Amount and Base allow −127…127. Inspect expression curves in MPE view; Slide/Pressure use their own lanes.
- **Ornament:** choose Flam for one added note, or Grace Notes for equal-length ornaments. Position is a percentage of the **grid**, not original-note duration: positive values replace the note's beginning, negative values prepend; ±100% occupies one grid division. Flam/Grace Notes Velocity is relative to source velocity. Grace Notes High/Low alternates every other ornament one semitone/degree above/below the original; Same keeps pitch. Amount sets count and Chance is relative to source Chance. Reapplying adds further ornaments; inspect before repeating.
- **Quantize:** choose current grid or an explicit subdivision, including triplets; target Starts, Ends, or both. End quantization changes note duration. Amount applies a partial timing correction rather than full alignment. Use Edit → Quantize (Primary+U) to reuse settings; open **Quantize Settings…** by name to inspect them. Recording quantization and manual grid-snapping are alternatives when those scopes are intended.
- **Recombine:** choose Dimension = Position, Pitch, Duration, or Velocity. Apply Shuffle, then Mirror, then Rotate, in that fixed order when combined. Shuffle redraws a permutation on each Apply; Mirror reverses assignment order; nonzero Rotation Steps circulates values (positive clockwise, negative counter-clockwise). Normally there are note-count minus one rotation steps; for Position, **Rotate on Grid** instead derives steps from grid cells. Use the display columns or Rotate Step Down/Up; check the chosen dimension rather than assuming whole notes move.
- **Span:** Legato reaches the next selected note, with the last reaching selection end or loop end; Tenuto keeps lengths unless modified; Staccato uses half the smallest distance between selected note starts as its base length. Offset moves ends up to one grid step (positive extends, negative shortens). Variation has the **opposite sign convention**: positive shortens, negative extends, generating fresh variation on each Apply when nonzero.
- **Strum:** set Strum Low and/or Strum High nonzero to offset a chord from its lowest/highest note. Positive moves later, negative earlier; ±100% moves the respective endpoint by one grid step, with intermediate notes following the display. Tension 0 spaces them evenly; positive Tension starts with larger gaps that shrink exponentially, negative starts with smaller gaps that expand. Inspect start order and boundary crossings.
- **Time Warp:** map a speed curve to the time selection using one to three enabled breakpoints. Drag them or set Breakpoint Time/Speed for the selected point. Quantize snaps the result to grid; Preserve Time Range fits the original span; Include Note End also warps ends and hence lengths. Use for accelerando/ritardando in note timing, not a promise to change the Set tempo.
- **Velocity Shaper:** edit envelope breakpoints and Minimum/Maximum Velocity; Loop repeats the envelope over the selection. Rotate offsets it in steps sized by Division (Rotate 1 with Division Grid shifts one grid step right). Inspect velocities, not pitch/timing. Requires the bundled Max tool availability described above.

## Generator catalog
- **Rhythm:** choose Pitch or a Drum Rack pad (also Alt/Option-click the piano ruler), Steps up to 16, Density as note count, and Pattern for placement. Pattern choices depend on Steps/Density. Step Duration determines repetition and can limit available Steps: eight 1/8 steps fill a 4/4 bar once; eight 1/16 steps repeat twice. Split is the probability of halving a step; Shift moves by whole steps (positive right, negative left). Velocity sets ordinary notes; Accent sets accent velocity; Accent Frequency ranges 0…Density and counts accented notes too, so 1 accents every note. Accent Offset moves accent placement. Deselect generated notes before adding another pitch/pad layer.
- **Seed:** constrain random notes with Pitch/Key Track, Duration, and Velocity ranges. Merging handles selects one value; click the range or set distinct min/max values to restore two handles. Alt/Option-click/drag the ruler chooses one pitch/a range. Duration spans 1/128 note to a whole note; velocity spans 1–127. Voices limits simultaneity; Density controls total population as a percentage of the pitch range. Purple pitch-range display indicates an active clip scale. Verify range and polyphony rather than expecting a repeatable melody.
- **Shape:** choose a Shape Preset or draw the contour; set Minimum/Maximum Pitch (or Alt/Option-drag a range). Rate is the minimum note length; Tie probabilistically extends to the next note. Density populates a percentage of the shape. Jitter 0 follows the contour exactly; higher Jitter randomizes pitch but remains inside the specified range. Purple indicates scale-aware generation.
- **Stacks:** add chords to fill selection/loop. Drag the Chord Selector Pad or use Primary+Up/Down; read the Status Bar for chord details instead of guessing from its interval diagram. Add Chord/Delete Chord changes progression length. Chord Root follows the clip scale initially and is restricted to its degrees while active; set another allowed root by knob, arrows, or Alt/Option-clicking the ruler. Positive Chord Inversion cycles voicings; negative cycles them one octave lower. Chord Duration and Offset move in eighths of the original chord length. Controls always belong to the currently selected chord.
- Stacks custom banks use JSON-based `.stacks` files. To load an already validated bank, put it in a browser Places folder and double-click it; this replaces the default bank. Find banks through the Stacks tag in MIDI Tools or the MIDI Tool content tag. Do not invent a bank schema from the chord diagrams.
- **Euclidean:** generates up to four voices in selection/loop. Pattern contains voice toggles, per-voice Rotation, and a central randomizer for rotations. Voices assigns pitches/pads and individual velocities; arrows beside the voice toggles shift all pitch/pad assignments together. Steps sets pattern length; Division sets step length; Density sets pattern repetitions within the selection. Short patterns repeat and notes may wrap around selection boundaries. Check wrapping and each enabled voice; the circular display alone does not prove the intended timeline result.

## MPE editing and routing
1. For recording, enable the controller's **MPE Mode** in Tempo & MIDI Settings (named Link, Tempo & MIDI in some builds). Its track input then uses All Channels, not an individually selectable channel. Per-note expression can be edited in **any** MIDI clip, including one not recorded by an MPE controller.
2. Click the **Note Expression** tab in Clip View. Verify any keyboard binding in the installed UI: focusing the clip editor is not necessarily switching to its MPE tab. Five dimensions are available: Pitch (per-note bend), Slide (per-note Y-axis), Pressure (polyphonic aftertouch), Velocity, Release Velocity. Pitch normally overlays the notes; Slide/Pressure have visible lanes by default; expose other lanes as needed. Lane toggles and the triangular all-lanes toggle control visibility; Alt/Option-click the triangle shows all. If no lanes are enabled, clicking the triangle shows all lanes. Resize individual dividers or the main lane/editor divider. A blue bottom dot in a MIDI meter indicates per-note controller traffic, not proof that the instrument responds correctly.
3. Select a note/envelope to expose its breakpoints; other notes dim. Click a segment to add a breakpoint, click a breakpoint to remove it, drag to move, or use context-menu **Edit Value / Add Value** for exact numbers. Selected points move relatively together. Drag the background for a selection; select a segment by clicking near it or Shift-clicking it. Dragging a selected segment inserts boundary points so the selected region moves together.
4. Note Expression has an independently saved grid, off by default. Enable Snap to Grid when needed; points can snap to grid lines/neighboring breakpoint times. Shift constrains a drag axis and enables finer vertical adjustment. Moving a point/segment across another can remove the neighboring point: inspect the resulting shape.
5. Alt/Option-drag a segment to curve it; Alt/Option-double-click restores a straight line. For Slide/Pressure/Velocity/Release Velocity, click outside the note, hover until its envelope turns blue, then drag to scale proportionally; this also works across selected notes. To offset all breakpoint values equally instead, click the envelope, Primary+A, then drag. Pitch does not use the proportional scaling gesture.
6. Moving a note carries expression; stretch markers and ×2 / /2 stretch it. Pitch values snap to semitones with grid override when grid is off; the same modifier bypasses this when grid is on. Fold hides the overlaid pitch envelopes; use an available Pitch Bend lane or unfold. Z fits the selection including pitch bends. **Clear All Envelopes** clears expression on selected notes, not the notes themselves; use only for an intended reset.
7. B enables freehand drawing of Pitch/Slide/Pressure; hold B for a temporary mode switch. With the grid enabled, drawing creates grid-width steps; grid override temporarily enables this when the grid is off. Shift gives fine vertical values. Inspect the actual selected note, especially where several overlap.
8. Use an MPE-capable instrument/preset for audible expression. Supporting Live devices also allow Push 2 polyphonic aftertouch. A plug-in's MPE Mode state can be saved with its device default; MPE-enabled plug-ins with MIDI outputs can also send MPE. Support is instrument-specific; do not infer it from visible envelopes alone.
9. For external hardware, set the output target in **Ext. Instrument** or the MIDI track's **MIDI To**, choose **MPE**, reopen that chooser, and select **MPE Settings…**. For an MPE-enabled plug-in, use its device-title context menu. Multi-timbral non-MPE instruments may use an appropriate multi-channel configuration; confirm their requirements.
10. **MPE/Multi-channel Settings** configures output only. Choose lower/upper zone and note-channel count, or multi-channel mode for an arbitrary note-channel range. One track outputs one zone; use two tracks for both. Lower zone reserves global channel 1, upper reserves 16; allocate other channels for note polyphony without overlap (for example lower 1–11, upper 12–16). Two tracks may share a MIDI output while targeting separate zones/sounds. Do not treat these output zones as input-zone filtering.

## Audio to MIDI
Select an audio clip and use Create or its context menu. Choose by the intended result:

| Method | Input and output |
| --- | --- |
| Slice to New MIDI Track | Retain the original audio as time slices; no pitch/harmony analysis. Produces a MIDI clip and Drum Rack, one Simpler chain and trigger note per slice. |
| Convert Harmony to New MIDI Track | Extract polyphonic pitches; creates notes with a piano Instrument Rack, not slices of the original sound. |
| Convert Melody to New MIDI Track | Extract one melodic line; creates notes with a synthesizer Instrument Rack. Synth to Piano morphs the preview toward electric piano; replace the instrument if needed. |
| Convert Drums to New MIDI Track | Extract unpitched percussion timing and attempt kick/snare/hi-hat classification into a preloaded Drum Rack. Classification is not guaranteed. |

- For slicing, choose beat divisions, transients, or Warp Markers and a Slicing Preset. Maximum **128 slices/chains**: if blocked, use coarser divisions or a smaller selected region. User presets come from the User Library Defaults folder.
- **Preserve warped timing** retains timing changes from warping; off uses the original unwarped timing. Allow processing to finish, then inspect the chromatic staircase of trigger notes and one Simpler per slice. Factory macros commonly address envelopes and loop/crossfade controls across all slices; actual mappings depend on the preset.
- Resequence by moving MIDI notes, or swap Drum Rack pads to change note mappings. Put audio effects in individual slice chains; to share processing, group selected chains into a nested Rack and place effects after that sub-Rack. MIDI effects such as **Arpeggiator** or **Random** go before the Drum Rack when the goal is changing triggers, not processing slice audio.
- For transcription, use isolated sources with clear attacks and high-quality uncompressed WAV/AIFF. Swells may be missed; accompaniment can create false notes; lossy material can yield unpredictable results, particularly at lower bitrates. Add/move/remove transient markers before conversion to change note divisions. Compare generated onsets/pitches/classes with the intended phrase and correct the MIDI; changing the preview instrument cannot repair wrong notes.
- Deliberately mismatching conversion type can create new material (Harmony on a single line may invent chords), but do not label that result accurate transcription.

## Grooves
1. Drag an `.agr` groove from the browser onto a MIDI clip or a **Warp-enabled** audio clip. Use the clip's Groove Hot-Swap button to audition alternatives. Double-clicking a groove loads it into the **Groove Pool** without necessarily assigning it; open the pool from the browser view menu or Primary+Alt/Option+6. Unused entries have grayed parameters.
2. Adjust a pool entry to affect **all clips using that groove**, not just the currently viewed clip. Save/hot-swap with the buttons beside its name. Set Base and Quantize before assessing Timing/Random/Velocity.

| Control | Practical consequence |
| --- | --- |
| Base | Reference grid for comparing groove-note offsets (for example quarters versus eighths); on-grid groove notes produce no timing offset at that location. |
| Quantize | Straightens source notes toward Base **before** groove timing; 100% fully aligns first, 0% retains original positions first. |
| Timing | Amount of the groove's timing displacement. |
| Random | Independent timing variation for each voice; a simultaneous chord can become spread out. |
| Velocity | −100…+100; negative values invert the groove's loud/soft pattern. |
| Global Amount | Scales Timing, Random, and Velocity for every groove, not Quantize; 100% uses set values, maximum 130% exaggerates them. Also appears in the Control Bar when grooves are assigned. |

3. Keep groove assignment non-destructive while refining. **Commit** writes note timing into MIDI or creates audio Warp Markers, then changes the clip's Groove to None; confirm this before further pool adjustments.
4. To edit a groove's underlying pattern, drag it from browser/pool into a MIDI track, edit that new clip, then **Extract Groove** or drag the edited clip to the pool. Extraction from audio/MIDI captures timing and volume from only the clip's playing portion; set that portion intentionally.
5. For reversible straight quantization, use any groove with Timing/Random/Velocity at 0 and set Base/Quantize; the groove pattern itself is irrelevant. For voice-specific groove, extract the relevant Drum/Instrument Rack chain to its own track/clip before assigning a different groove. For requested doubling, duplicate the track and apply Random to one copy; verify the independent offsets rather than assuming locked unison.

## Tuning systems
- Live 12 defaults to **12TET**. Custom systems may divide octaves unequally or repeat at a non-octave interval. Load `.scl` or Ableton-extended `.ascl` files; the Tunings browser label includes Core Library systems. Hover a file or loaded name for its description/note count. Put custom files in a browser Places folder to find them under the User tag.
- All built-in Live instruments support tuning systems. MPE-enabled plug-ins/external Max for Live instruments require a **48-semitone pitch-bend range**; non-MPE instruments or other ranges may be out of tune. Confirm the receiver setting before changing clip notes to compensate.
1. Double-click a tuning file / select it and Enter, or drag an external file into the browser's **Tuning** section. The section can also be shown through the browser view menu. A loaded tuning is saved with the Set. Piano-roll rows now denote tuning notes, not ordinary MIDI pitches; hover notes to inspect pitch/frequency in the Status Bar.
2. Decide how existing notes should behave **before** switching/removing tuning. Normally their row positions remain and their sounding pitches change. **Retune Set On Loading Tuning Systems** instead remaps notes toward their former pitches and prompts for confirmation. Overlapping notes may collapse onto one pitch, shortening/removing a note. Preserve a copy and compare note counts/overlaps; do not promise lossless round trips.
3. Expand the triangle beside the tuning name. **Octave / Note** chooses the reference note; **Ref. Pitch/Freq** changes its frequency and shifts the Set's tuning. Changing Octave/Note alone updates the displayed corresponding frequency **without an audible retune**. **Lowest Note / Highest Note** relocate the available note range together, preserving its size. Use Save Tuning System to save the adjusted system as `.ascl`; removing the loaded tuning returns to 12TET, subject to the retuning caveat above.
4. Loaded tuning hides the normal Scale Mode choosers and disables scale-aware devices' **Use Current Scale**. Do not troubleshoot this as a missing clip-scale feature. MIDI-track **Bypass Tuning** restores 12TET for that track; Drum Rack tracks bypass automatically.
5. For keyboard mapping, choose **All Keys**, **Black Keys Only** (centered C#3), **White Keys Only** (centered C3), **Closest in Pitch to Keyboard**, or **Custom Controller Layout**. Custom opens **Configure MIDI Layout** via the … button and is saved with the Set. Match controller layout to intended piano-roll rows, then verify played pitches. Do not infer unavailable dialog controls or author custom ASCL syntax without a validated format specification.

## Session clip launching
- Launch controls apply to **Session** clips only; Arrangement clips play by timeline position. Double-click a Session clip and open the panel bearing the launch-button icon. Multi-select first to change several clips' launch settings together.

| Launch Mode | Press/release behavior |
| --- | --- |
| Trigger | Press starts; release does nothing. |
| Gate | Press starts; release stops. |
| Toggle | Press starts, next press stops; releases do nothing. |
| Repeat | Holding retriggers at the clip quantization interval. |

- **Legato Mode** takes the previous clip's play position in the same track rather than restarting. Use it to switch aligned variants, including with quantization off. It is unrelated to note-length Legato. Different samples may suffer disk-preload dropouts; Clip RAM Mode is the offered remedy. Check memory headroom before enabling it broadly.
- **Clip Quantization** chooses an explicit launch grid, None, or Global (Control Bar setting). For precise Follow Action intervals, choose None; explicit local quantization can delay launches. Do not rely on Global to align Follow Actions without verifying installed-version behavior.
- **Velocity Amount** controls the effect of incoming launch-note velocity on clip volume: 0 ignores velocity; at 100%, the softest notes make the clip silent. It does not edit velocities inside a MIDI clip.
- **Nudge Backward/Forward** jumps within playback by the global quantization period. Map these buttons to keys/MIDI if needed; MIDI Map Mode exposes a scrub control between them for a rotary encoder. Launching/nudging/scrubbing with quantization below one bar can offset the clip relative to the master clock; check phase after the move.

## Follow Actions
1. A clip group is a contiguous run of occupied slots on **one track**; empty slots separate groups. Set clip controls in Clip View, scene controls in Scene View. Enable the selected clip/scene's Follow Action button (Shift+Enter); it starts disabled. Assigned actions produce striped launch buttons.
2. Choose actions A/B and inspect **Chance A / Chance B** as percentages. Use A=100%, B=0% for deterministic A. The slider between them adjusts the split; verify both displayed percentages rather than interpreting them as independent odds.
3. Clips default to **Linked**: act at clip end, or after the number of loops in Follow Action Multiplier. **Unlinked** uses Follow Action Time measured from the launch point in bars–beats–sixteenths; default is one bar. Scenes have Follow Action Time but not the clip Linked switch. Drag the clip's Follow Action Time marker to adjust its duration.
4. Explicit per-clip launch quantization can defer a scheduled transition; use None for an exact-time test. Global quantization is not a reliable substitute for explicit clip timing here. Scene Follow Actions take priority when they fire, although clip actions keep running while the scene action is merely pending.

| Action behavior | Choose when |
| --- | --- |
| No Action | End further follow decisions for this launch and let current playback continue under its own clip settings; it does not mean Stop. |
| Stop | Stop at the follow time, overriding loop/region continuation. |
| Play Again | Restart the current clip. |
| Previous / Next | Move to neighboring clip; Next wraps from the group's last clip to its first. |
| First / Last | Choose the group's top/bottom clip. |
| Any | Randomly choose a clip in the group, including the current one. |
| Random without consecutive repetition | Exclude immediately repeating the current clip unless it is the group's only member; identify this option in the installed chooser. |
| Jump | Set **Jump Target** to the specific clip slot or scene by dragging/typing its number. |

- **Enable Follow Actions Globally**, beside Back to Arrangement, temporarily suspends all clip/scene actions so running material can be edited without jumps. It is grayed when no actions exist. Verify the global state as well as the per-clip state when diagnosing a missing transition.
- **Intro then looping tail:** split a preserved copy into a non-looping intro and looping tail; place them adjacently on one Session track. Set the intro's action to Next at its end (or exact duration), A=100%/B=0%; loop the tail. Confirm the transition preserves the intended boundary.
- **Cycle:** use Next on each member, or Create Follow Action Chain on selected clips (selection need not be contiguous). Add a lower-chance random branch only when variation is requested; inspect generated targets for noncontiguous chains.
- **Temporary repetition:** on a long non-looping clip, use unlinked one-bar Play Again at 80%, No Action at 20%. No Action releases playback into the remainder; it is stochastic, not a fixed repeat count. Alternatively advance to a second instance with a loop region and its own exit condition.
- **Synchronized variation:** put related clips in Legato Mode and vary notes, envelopes, transposition, or warped playback while Follow Actions change clips; inherited beat position avoids restarting the phrase. For segment reshuffling, vary start/end markers and match each follow duration to the segment meant to play.
- **Long evolving structures:** use different/odd durations and A/B branches across groups; this can reduce obvious repetition but does not prove mathematical nonrepetition or indefinite reliable operation. Verify the behavior over a representative test interval.

## Verification and recovery
- Confirm selection scope, note counts, pitch range, note lengths, overlaps, loop boundaries, and visible expression after transformations. Check repeat-dependent Chance/Deviation over several passes, not just one.
- If the wrong notes changed, Undo note edits; Reset on a MIDI Tool will not restore them. If nothing changes, check active selection, Auto Apply/Apply, muted notes, Chance, Focus Mode, and whether the operation is only changing visibility.
- If pitches/expression are wrong, check instrument/MPE support, 48-semitone tuning bend range where applicable, Bypass Tuning, controller layout, and output zone/channel assignments before rewriting the performance.
- If groove or launching seems inactive, check Warp for audio grooves, groove assignment versus pool-only loading, global/per-clip Follow Action enables, empty-slot group boundaries, local quantization, and scene precedence.
- These checks describe what to inspect; they are not claims of auditioning, a successful Live test, or verified automation support.
